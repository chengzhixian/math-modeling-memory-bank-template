# B7 质量×规模候选比较预注册（运行前冻结）

日期 2026-09-24；在运行 `src/cyj/compare_b7_quality_interactions.py` 之前建立。任务 3 已使用全部 B7 发现组内 Q 斜率变化，因此**模型族的发明不是盲于 B7 的**。下列嵌套 CV 只能比较固定算法在同源半合成 B7 上的稳定性，不能称完全未触碰的最终测试，更不能证明真实训练机制。若需无偏外部验证，须获得新且同口径的独立数据。

## 数据角色与支持

只使用 B7 的 450 个唯一 `(N,D,Q)` 点；B6 为 B7 子集，B8 方向冲突，B1/A Loss 坐标未桥接，均不参加训练/选模/检验。B7 的 9 个 N、5 个 D、10 个 Q 等级构成网格；单位分别为 10^9 参数、10^9 token 和原生 `Q_score`。当前矩形内未见坐标仍属插值假设，范围外不作预测结论。每个 N/D 组的十个 Q 在涉及 N/D 的划分中整组留出。

## 冻结候选与估计规则

全部候选先在该训练折上拟合 no-Q 的五参数基线 `E+A N^-alpha+B D^-beta`，要求 E/A/B>0、alpha/beta∈[.02,1.5]、收敛且不触边。该训练折估得的 alpha/beta 随后对所有候选固定；这是共同的**两阶段算法**，因此本次 constant-G 与旧版对各候选分别联合拟合的数值不可直接视为相同。第二阶段 OLS 估计下式线性系数，训练折设计矩阵须满秩：

| 名称 | 在共同 N/D 基础上追加的项 | 参数增量 |
|---|---|---:|
| `no_Q` | 无 | 0 |
| `constant_G` | `g0(1-Q)` | 1 |
| `Q_x_logN` | `[g0+gN ln(N/1B)](1-Q)` | 2 |
| `Q_x_logD` | `[g0+gD ln(D/100B)](1-Q)` | 2 |
| `Q_x_logN_logD` | `[g0+gN ln(N/1B)+gD ln(D/100B)](1-Q)` | 3 |

为保持训练物理符号，要求线性阶段 E/A/B>0；对含 Q 项者，训练 N/D 网格上 `G(N,D)≥0`，否则此折该候选无效。不得通过减少惩罚或增加项挽救单折失败。无 Q 基线梯度为 0；其他候选 `∂L/∂Q=-G(N,D)`。记录参数、触边/失败、全声明支持角点的梯度范围。

## 划分、选择与报告

外层分别留 9 个完整 N 级、5 个完整 D 级、10 个完整 Q 级，共 24 折。外层测试折只用于评估固定内层选择规则。对每个外层训练集，内层从**相同轴**逐级留出，在剩余级上选择平均折 RMSE 最小候选；同分按上述表顺序选最简单者。折内所有估计只读其训练行，绝不预读外层待评估 Loss。若某候选在内层任一折无效，内层分数置无穷；若所有候选失效则显式失败。外层重拟合选中的候选，保存逐点预测、残差、RMSE、MAE、均值偏差、每 N/D/Q 等级 RMSE、候选选择频次。外层 N/D/Q 留级属于同源分组泛化，不能把 24 折点合并称独立外测。

另报告全 B7 拟合的候选训练误差、参数与梯度范围；不以全样本误差选科学主模型。100 次按 45 个 N/D 组有放回抽样，固定随机种子 `20260924`，记录各候选关键参数/梯度的成功与失败，以检查条件估计稳定性；bootstrap 不包括半合成构造、模型发明或真实外部误差。若计算成本过高，允许先运行外层/内层并将 bootstrap 标为未运行，不填假区间。
