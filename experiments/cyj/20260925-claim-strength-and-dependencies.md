# CYJ 结论强度与外部依赖

本表约束论文、接口和交接用语。方法与结果仅依据可见题面、源数据及本人独立运行的记录；被清理 PDF 的历史隐藏内容和已作废提交没有进入证据链。

| 对象 | 可允许结论 | 不可提升为 |
|---|---|---|
| B1 同源经典拟合 | 附件 B1 规则网格中的描述性重构；生成和评估机制未识别 | 真实训练 scaling 定律的独立验证 |
| B7 joint NDQ 拟合 | B7 半合成支持域内的条件均值候选 | 真实 LLM 普适机制或逐参数物理解释 |
| B7 nested CV | 五族内选、N/D/Q 外留级的同源条件泛化，24 折/1350 OOF | 未触碰真实数据的最终外测；全 B7 历史探索无法撤销 |
| nested OOF 对称残差区间 | 三轴 80/90/95% 外留级覆盖的条件校准 | v4 bootstrap+残差区间的直接覆盖保证 |
| B7 Q 边际与等损失替代 | 已声明函数族及域内局部/有限变化计算 | 因果质量干预效果 |
| B7/B8 冲突 | 共 224 坐标、对应 Loss 全异，固定 ND 斜率方向相反；两源隔离 | 合并拟合或简单反转 B8 Q |
| Q3 330 网格与转变点 | 给定 B7、成本族、预算、Q0 和支持域的条件诊断 | 真实训练全局最优配置和普适预算阈值 |
| A 侧 p 敏感性 | CHM 固定 1M、13 target 的对比向量 | 可加入 B7 Loss 的 `L(N,D,Q,p)` |
| 跨附件真实外推 | 当前无可识别映射 | 任何跨 A/B Loss 或 Q 单位换算 |
