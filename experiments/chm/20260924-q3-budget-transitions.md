# Q3 连续预算扫描与结构转移诊断

日期：2026-09-24（北京时间）  
角色：chm  
状态：diagnostic only；不解除 `ready_for_Q3=false`

## 1. 目的

在 cyj 的 Q/p 正式桥接尚未完成时，先把不依赖这些未知量的 N-D 优化结构推导完整，并为后续数值 solver 提供解析基准。这里固定 Q=Q0、p=p_ref，因此质量成本为 0，p 对 Loss 的跨坐标修正为 0。

## 2. 内点闭式解

令

[
c(L_c)=6\times10^{18}+2\times10^{14}L_c
      =6\times10^{18}\left(1+\frac{L_c}{30000}\right),
]

预算约束在最优内点处取等号：

[
ND=P=\frac{C_{\max}}{c(L_c)}.
]

对

[
L_0=E+A N^{-\alpha}+B D^{-\beta}
]

应用一阶条件：

[
N^\star=
\left[
\frac{\alpha A}{\beta B}P^\beta
\right]^{1/(\alpha+\beta)},
\qquad
D^\star=\frac{P}{N^\star}.
]

因此内点预算弹性为

[
\frac{d\log N^\star}{d\log C_{\max}}
=\frac{\beta}{\alpha+\beta}
=0.451528,
]

[
\frac{d\log D^\star}{d\log C_{\max}}
=\frac{\alpha}{\alpha+\beta}
=0.548472.
]

在当前 B1 诊断模型下，预算增加时 D 的最优增长弹性略高于 N。

## 3. 结构转移定义

本阶段不把“三档预算下成本份额看起来不同”称为结构转移。定义结构转移为**最优解活跃约束集合发生变化**。

在当前参数和 B1 支持域中，路径依次为：

1. 预算小于最小支持成本：无可行解；
2. `N=N_min`；
3. N-D 内点；
4. `D=D_max`；
5. `N=N_max,D=D_max`，支持域角点，继续增预算只增加预算松弛。

`D_min` 和“内点直接撞 `N_max`”不是当前参数下的实际最优路径。

## 4. 精确阈值

| Context | 最小可行预算 | N_min→内点 | 内点→D_max | 支持域角点 |
|---:|---:|---:|---:|---:|
| 2048 | 6.059e16 | 7.948e17 | 9.326e21 | 2.300e22 |
| 8192 | 7.220e16 | 9.472e17 | 1.111e22 | 2.741e22 |
| 131072 | 3.045e17 | 3.995e18 | 4.687e22 | 1.156e23 |

单位均为 FLOPs。

2001 个 ([10^{16},10^{24}]) 对数预算点自动扫描可在单步网格分辨率内恢复全部解析阈值，没有发现额外活跃集转移。

## 5. 上下文临界长度

[
\frac{C_{attn}}{C_{train}}
=\frac{L_c}{30000}.
]

因此 30000 Token 是 attention 成本与训练主成本相等的解析临界长度。它只用于成本结构解释，**不是 C7 中新增的观测情景**。

在内点、同预算下，相对 2048 Token：
- 8192 Token：N 缩放到 0.9239，D 缩放到 0.9083；
- 131072 Token：N 缩放到 0.4824，D 缩放到 0.4125。

## 6. 解释边界

这些转移只针对 cyj 当前 B1 N-D diagnostic，且严格限制在其声明支持域。尤其高预算到达支持域角点以后，不能把预算松弛解释为“继续增加算力没有收益”，只能说明当前 predictor 没有经过该区域验证。

正式 Q3 仍需 cyj 的 B-native Q 性能模型、p anchor/lambda 处理、总不确定性及 `ready_for_Q3=true`，同时需 zhh 更新正式 C7 接口状态。
