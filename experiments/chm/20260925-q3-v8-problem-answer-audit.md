## C. Gate 结论与发现

**BLOCKER（正式跨源解释）**：A/B 没有同 N/D/p/Q 的配对观测，无法识别 `phi`、配比桥幅度、规模衰减，且 Q 代理与 p 效应可能重叠。v8 的 `L=[L_B1+(1-Q_B)G(N,D)]exp(r_w(p))` 只作为具名情景；未产生真实训练最优配比、联合 95% 区间或 Benchmark 增益。修复需要可比 Loss 坐标的配对干预或独立外部实验，不能靠继续优化数值。

**MAJOR（质量与配比口径）**：Q1 无约束主配方映射成 `Q_B_proxy≈0.38578`，低于本轮 `Q0=0.5`，不可塞进 `Q≥Q0` 的主场景。改用 Q2 v8 已发布、A4 已观测且满足 Q1 direct+near 政策的配方 172（Q≈0.67136）；再对符合质量政策和 `Q≥Q0` 的 87 个已观测配方精确枚举。剩余连续 A4 凸包不能称已全局优化。若改变 Q0 或映射函数，全部 Q3 表须重算。

**MAJOR（数据角色与支持）**：B6 的坐标嵌在 B7 中；B7 半合成质量族在既有研究中已用于形式比较，嵌套折不能冒充未触碰独立最终测试。B8 的同坐标反向质量趋势保持隔离；B3 是插值轨迹，B10 是 estimated 外推压力，不参与本轮训练。B7 部分 N/D 超 B1，v8 取交集 D≤299.893；旧 v7 D≤600 和旧 36 行/42 转移是 legacy，不能直接迁移。A6–A11 曾用于 Q1 模型形式取舍，不能再称完全盲测。

**MINOR（数值边界）**：固定配比下先因 Loss 对 D 单调下降令 `D=min(Dmax,B/(cN+h(Q)))`，再在当前拟合参数 `A,B,alpha,beta>0`、`G_N,G_D≤0`、质量收益正的条件下，对 `log N` 的分段凸目标二分；新测试与独立 SLSQP 对照。浮点下界间隙为数值误差，不是严格区间算术。独立原生 Q 灵敏度使用现有降维误差界，33 可行格最大目标间隙约 `1.0e-7`；它不是 v8 主 baseline。`Q0`、成本正部、非有限数、同名变量跨源、配方和界在代码中显式拒绝或核算。

**NOTE（验证与文献适用）**：训练开销的 Chinchilla 近似与三成本族来自可见题面，真实硬件 FLOPs、数据清洗成本和长上下文注意力常数未单独测量。B4/B5 只能比较各自家族内方向，不能拿绝对 Loss 作为 v8 外部 RMSE。C7 131072 Token 是稀疏高端情景。原生 Q=1 模式可显示质量资源的数值机会，但不能等同 Q1 配比能把真实质量提升到 1。

## D. 公式、代码、消融与结构转移

- `src/chm/q3_conditional_v8.py` 对照 CYJ v8 `predict_baseline_v8` 的 `N,D,p,weights,p_policy,quality_mapping_policy`，每格再次调用上游预测器，分别保留 B1 backbone、v8 NDQ 代理 Loss 和条件桥 Loss。三成本为 `6e18 ND`、`2e14 L ND`、`1e9 D max(g(Q)-g(Q0),0)`；逐行验证三项和、预算、v8 N/D/Q 支持域。`p=172` 固定主策略与 87 个已观测候选枚举分开。`native_Q_sensitivity_grid.csv` 是单独的自由 Q 对照。
- 官方三预算 × C7 三上下文 × 三成本族 = 27 格；含额外 `10^20` 的表为 36 格。固定配方 172：30/36 可行；87 候选联立：33/36 可行；原生 Q 灵敏度：33/36 可行。三模式在 `10^19`、131072 Token 均不可行。`10^22`、8192 Token、幂成本时固定/离散联立同取 p172、N=6.660655431、D=193.873531189、Q代理=0.671360765、条件 Loss=2.094421151；原生自由 Q 对照取 Q=1、N=5.258740894、D=222.936279965、条件 Loss=2.023222216，跨模式不能把 Loss 差解释为真实收益。
- 成本族敏感性：在 `10^19`、2048/8192 Token，幂成本下固定 p172 都不可行，而联立可用 p477；对数成本 8192 Token 同样需要 p477。中预算 8192 Token 三成本族的固定策略 Loss 约 2.093894/2.094421/2.094113。`10^24` 时三族均到 N/D 支持上界，8192 Token 幂成本只用预算约 2.762%，这是支持域截断，不是剩余算力没有价值。
- 定义稳定状态 `S(B)=(可行性,配方编号,N/D/预算活跃约束)`。161 点/上下文/成本族对数扫描各用于固定策略和联立策略（各 1449 行），相邻异状态用二分细化到相对预算宽度 `<10^-4`，共有固定 33、联立 49 个括区。81 点粗网格在 131072 Token 的三个成本族会漏掉一串短暂配方状态；161 点和细化显示高端上下文在可行性边界附近依次出现 159、459、368、437、477、172 等已观测策略。因此只报告数值括区及分辨率，不称现实相变精确点或保证更窄状态不存在。8192 Token 幂成本下 p477→172 的预算括区约 `[1.610535,1.610648]×10^19` FLOPs；完整表在 `transitions.csv`。
- `Lcrit=30000` Token 来自 `2e14 L ND = 6e18 ND`。2048、8192、131072 的注意力/训练比分别约 0.0683、0.2731、4.3691；C7 情景外生，不能连续对 L 求内点最优。
