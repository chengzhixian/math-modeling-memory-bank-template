# Q3 p 支持域与多 target 稳健配比诊断

日期：2026-09-24（北京时间）  
状态：A-side scenario only

## 1. 为什么不直接在整个单纯形上优化

Q1 当前对 target k 的配比效应为线性函数

[
m_k(p)=\beta_k^\top(p-p_{ref}).
]

若只要求 (p_j\ge0,\sum p_j=1)，线性目标会自然推向单纯形顶点，而这些极端点大多没有训练支持。

本阶段把可接受支持域定义为 A4 512 个观测配方的凸包。对线性目标有

[
\min_{p\in\operatorname{conv}(P_1,\dots,P_{512})}m_k(p)
=
\min_i m_k(P_i).
]

因此在当前线性 p 模型下，直接枚举 512 个观测配方与凸包内优化等价。若 (lambda\ge0) 且 eta 固定，正的尺度因子不会改变 p 的排序，所以单 target 最优 p 与 N、预算和上下文无关。

## 2. 单 target 最优仍然非常极端

五个敏感性 target 的最佳 A4 配方分别为：

- pile_cc：index 291，约 98.8% pile_cc；
- wikipedia_en：index 171，约 70.9% wikipedia；
- arxiv：index 300，约 90.2% arxiv；
- stackexchange：index 389，约 99.8% stackexchange；
- github：index 292，约 95.4% github。

这说明“限制到真实训练配方”只能防止超出 A4 支持，并不能解决单 target 目标本身的偏科行为。

## 3. 多 target 稳健准则

由于五个 target 的原始 Loss 尺度不同，不把 raw m_k 直接平均。对每个 target 先按 512 个 A4 配方上的横截面标准差标准化，再定义：

- standardized mean：五个 z 效应均值；
- standardized minimax：最坏 target 的 z 效应；
- mean rank：五 target 百分位排名均值。

结果：
- standardized mean：index 326；
- standardized minimax：index 139；
- mean rank：index 177。

其中 index 139 最均衡：
- 14 个非零域；
- effective domains≈8.824；
- 最大单域权重 0.201；
- 五个 raw m_k 均小于 0。

## 4. 相对 p_ref 的五目标共同改善

512 个 A4 配方中只有 3 个在五个 target 上都满足 m_k<0：

- index 35；
- index 99；
- index 139。

占比 3/512≈0.586%。index 139 位于五目标 Pareto 前沿。

这只是当前五个 A-side Ridge 代理相对 p_ref 的**预测共同改善**，不代表 B1 val_loss 或真实下游能力必然改善。

## 5. Q3 使用建议

如果 cyj 最终能识别 B1 primary anchor 和 lambda，应按其正式接口使用。

如果 anchor/lambda 始终不可识别，论文不应伪造唯一 p 最优值；更稳妥的输出是：
1. 五个单 target 情景；
2. index 139 的 standardized-minimax 稳健情景；
3. 35/99/139 三个“五目标共同改善”配方敏感性；
4. 明确全部属于 A-side p scenario。

这样既保留题目要求的配比优化，又不跨越 Loss 坐标不可识别边界。
