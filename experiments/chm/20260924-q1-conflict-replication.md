# Q1 指标冲突的扩展集/非重叠复制性

日期：2026-09-24（北京时间）

## 目的

现有 A1 冲突表只说明样本内不同质量指标可能负相关。A2/A3 包含 A1 中 arxiv/github 的全部样本，因此直接比较 sample vs extended 不能称独立验证。本实验再使用已经生成的 non-overlap 扩展结果，检查负相关在剔除重叠记录后是否保留。

## 结果

### arxiv

231 个指标对中：
- A1 sample 负相关：96；
- sample、完整扩展、非重叠扩展三者均负：92；
- 占 sample 负相关的 95.83%；
- sample 与完整扩展符号一致率 96.10%；
- sample 与非重叠扩展符号一致率 95.67%。

### github

231 个指标对中：
- A1 sample 负相关：91；
- 三层均负：91；
- 占 sample 负相关的 100%；
- sample 与完整扩展符号一致率 99.13%；
- sample 与非重叠扩展符号一致率 99.13%。

### 两域共同复制

共有 56 个指标对在 arxiv 与 github 两个域里都满足 sample / extended / non-overlap 三层均为负。

最强共同复制对为：
`rps_lines_uppercase_letter_fraction` vs
`rps_lines_ending_with_terminal_punctution_mark`。

六个相关系数为：
- arxiv：-0.8191 / -0.8196 / -0.8195；
- github：-0.7393 / -0.7440 / -0.7442。

六者中最弱绝对值仍约 0.7393。

## 解释

这说明若干质量信号之间的负相关并非仅由 A1 与扩展集重叠记录造成，且在 arxiv/github 两个不同域上可复制。论文可以将这些指标对作为“质量信号存在结构性冲突”的例证。

但本结果仍然不是显著性检验：
- 尚未对逐记录相关做 bootstrap CI；
- 尚未对 231 个指标对做 FDR/多重比较控制；
- 不应使用“显著冲突”措辞。

下一步需要完整 LFS 原始记录运行独立统计脚本，补相关区间与多重比较；在此之前正文使用“稳定复现的负相关/冲突”而不是“统计显著”。
