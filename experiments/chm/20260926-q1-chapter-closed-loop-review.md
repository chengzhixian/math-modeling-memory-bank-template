## C. Gate 结论与修正

1. **可识别性与数据角色**：A1 质量为描述性综合分；A4/A5 的 1M 配方响应可在声明函数族和支持域内拟合。A6/A8 是相同的 256 个配方，不能当独立配方组累计；A10 的 64 个配方中 47 个在 A4 凸包外；A12–A15 的 Loss 属估算，不能称真实外测。缺少配方成对的训练 Token 量及 A/B 成对标定，故连续规模律与 A→B 桥接保持未识别。章节已纠正“冻结后 untouched held-out”措辞：最终系数不使用 A6–A11，但前期检验观察影响过模型族研究。
2. **文献适用条件**：RegMix 提供小模型配比回归的研究背景；Data Mixing Laws 的指数式在固定模型规模及训练量下讨论。Q1 采用自己的二阶交互函数，经当前数据比较，不以文献推定其成立；DoReMi、BiMix 仅用于说明多域决策存在不同目标口径。2026-09-26 依据原始 arXiv/数据卡页面核对 BibTeX，不采用题面参考表中可能有误的会议年份。
3. **公式、代码、单位与数值安全**：质量压缩、median–MAD、A1 冻结方向见 `src/chm/q1_quality_analysis.py`；交互式预测、正参考 Loss、17 维比例和非有限值检查见 `src/chm/q1_interface_v2.py`；质量覆盖、条件均分约束与目标权重见 `src/chm/q1_mixture_decision_v2.py`；McCormick 松弛、最宽坐标二分、容差 `0.001` 见 `src/chm/q1_hull_bounds_v2.py`。新增式 `eq:q1_quality_reference` 与 `eq:q1_complete_decision` 同代码的线性约束一致。基准配方 $\boldsymbol p_{\rm ref}$ 下所有 $r_k=0$；凸包约束保证非负且和为 1。A4 的舍入行先归一化，未把缺失质量域填成数值。
4. **基线、消融、敏感性与验证**：质量分比较等权、删除脆弱指标及 argmax 方案；冲突边在 A2/A3 去重集合复核；配比主模型与 Ridge、常数基线比较，嵌套五折防止交互特征选择泄漏。三个真实检验组按目标域的交互 Spearman 中位数为 `0.8512/0.8474/0.7912`；交互 RMSE 优于 Ridge 的目标数为 `11/13、13/13、13/13`，已由 `outputs/chm/q1_v2/targetwise_validation.csv` 独立汇总。训练扰动与目标权重敏感性限定具体配方推荐。
5. **结果与结论等级**：`bounds.json` 四情景的下界、可行上界、间隙和离散 index 与章节表逐项核对；`q1_v2_signoff/audit.json` 四项均 `passed=true`，但只是浮点数值界。评分和冲突模式属于 L1 描述性；限定支持的配比响应及排序属于 L2 预测性；没有 L3 普适结构、L4 因果或 L5 真实 10B/70B 外推主张。输出不直接视为 B 侧 Loss 或 Benchmark。
6. **从零反证**：仅看题面与表头，A1–A3 能建立可重复的相对评分及两扩展域复核；A4/A5 能估计 1M 配比到 13 个 Loss 的条件关系；A6–A11 只能测试给定实验组上的预测或排序；A12–A15 只能作估算压力。这与章节最终主张一致。替代解释包括训练量/其他训练条件变化及 1B 配方支持变化，故不把组间差异单独归因于参数量。
