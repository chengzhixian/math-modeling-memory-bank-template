# Q3 三类质量成本函数的成本侧敏感性

日期：2026-09-24（北京时间）  
角色：chm  
状态：diagnostic only；不包含 Q 的性能收益模型

## 1. 题面成本

质量成本统一为

[
C_Q=10^9D_B\max\{g(Q)-g(Q_0),0\}.
]

三类函数：

[
g_e(Q)=10^7e^{6Q},
qquad
g_p(Q)=5\times10^9Q^4,
qquad
g_l(Q)=2\times10^9\ln(1+10Q).
]

指数和四次幂均为凸函数；对数为凹函数。

## 2. Q0 处的非光滑性

因为使用正部函数：
- 当 (Q<Q_0)，质量增量成本为 0；
- 在 (Q_0) 左侧导数为 0；
- 在 (Q_0) 右侧导数为
  [
  10^9D_B g'(Q_0).
  ]

因此正式 solver 必须使用单侧导数/KKT，不能在 Q0 处把双侧导数错误写成 0。

## 3. 与其他成本的解析比例

训练主成本

[
C_{train}=6\times10^{18}N_BD_B,
]

注意力成本

[
C_{attn}=2\times10^{14}N_BD_BL_c.
]

令 (Delta g=g(Q)-g(Q_0)>0)，则

[
\frac{C_Q}{C_{train}}
=
\frac{\Delta g}{6\times10^9N_B},
]

[
\frac{C_Q}{C_{attn}}
=
\frac{\Delta g}{2\times10^5N_BL_c}.
]

两个比值都消去了 D。这不表示 Q 与 D 在优化中解耦，因为 (C_Q) 的绝对值和右导数仍与 D 成正比；它只说明三项成本的相对量级存在简洁解析阈值。

## 4. Q0=0.5 的示例

Q0=0.5 仅取自 cyj 的可复核接口算例，**不是官方固定基准**。

增量成本交叉：
- exp 与 log：Q≈0.7491088；
- power 与 log：Q≈0.5767453；
- exp 与 power 在 (0.5,1] 无增量成本交叉。

因此在该示例中：
- (0.5<Q<0.5767)：exp < power < log；
- (0.5767<Q<0.7491)：exp < log < power；
- (Q>0.7491)：log < exp < power。

四次幂在这个特定 Q0 区间内从未成为最低增量成本族，但不能据此把它从正式题面敏感性中删除。

例如 Q 从 0.5 提升到 0.8，使 (C_Q=C_{train}) 的 N 阈值为：
- exp：0.169B；
- power：0.289B；
- log：0.135B。

在 N 大于该阈值时，此次质量升级成本低于训练主成本；小于时反之。该判断只比较成本，不含质量对 Loss 的收益。

## 5. 对正式 Q3 的作用

当 cyj 发布 B-native (L_Q) 后，可把性能边际收益与上述成本边际导数结合：

[
\frac{-\partial L/\partial Q}{\partial C/\partial Q}.
]

在 Q0 处必须用右侧 KKT 条件；不同 g 的凸/凹性可能导致不同的质量投资结构转移，因此三种成本族必须全部保留做正式敏感性。

当前没有 (L_Q) 的 validated 接口，所以本实验不求最优 Q。
