## 本题共用的图文规范建议

1. 每个核心结论附近放对应图或表，并在图下注明数据范围、统计量和不能推出的结论。
2. 同一数据只用一种主图表达；表保留需要精确查数的结果，图强调排序、异质性与不确定性。
3. 使用克制的蓝—橙强调色，保持灰度打印可读；避免用颜色单独承载类别含义。
4. 初稿先保证图中数值、图注和复现文件一致；后续由集成人按正式模板统一编号、字体与版心。

这些是参考作品的表达技巧，不是本题方法或结论的证据。比赛规则、论文模板与匿名要求仍以当年官方材料为准。
