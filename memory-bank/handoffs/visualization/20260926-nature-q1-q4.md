# 独立 Nature 图组交接

源码及全部首轮输出在 `src/visualization/nature_answers.py`、`outputs/nature/`。同一画图分支，输入 main@f3a49d4，未用旧 SciPilot 图作设计输入。

最终22组、53面板完成，所有自动渲染门禁通过，实际字形≥5.25pt；逐图及变更后的视觉复核完成。冻结输入哈希、183mm页宽、600dpi TIFF、SVG文字已核对。README给出全部答案覆盖、图型契约、正文与附录建议；`gallery.html`、`legends.md`和`figures.pdf`为交付入口。

只调整可视化，未修改模型、主答案或正文。图注分别说明统计区间、确定性假设范围、优化数值界、estimated证据和不可行缺口。需要选图时以Nature图组为独立候选，而非自动替换论文所有图。源码重跑将重置视觉验收，应再读图。
