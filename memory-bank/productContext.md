# 题意与验收背景

依据本地 F 题题面初始化。以下为任务要求摘述，不代表已验证的研究结论。

题目研究有限算力下参数规模 N、数据量 D、质量 Q 与领域配比 p 的取舍。交叉熵 Loss 与下游 Benchmark 相关但不等价，必须通过桥接关系说明联系与误差。

## 四问依赖

1. 问题一输出质量评价、冲突分析以及 17 域配比与 Loss 的关系，为第二问提供 Q 与 p 的结果接口。
2. 问题二融合不同来源信息，估计并验证包含 N、D、Q、p 的广义标度律，分析边际效用、弹性和替代条件。
3. 问题三使用前两问结果，在算力约束下优化配置；上下文长度由 C7 支持的情景外生给定，不作为内点寻优变量。
4. 问题四分离规模扩张与非规模技术进步，建立 Loss–Benchmark 桥接，分析未来 12 或 24 个月开源能力前沿及不确定性。

## 不能遗漏的数据验收项

- Q1：A1、A2、A3 全量质量信号；22 个指标统一方向，列表型指标先压缩；抽样与扩展集域级 Q 对照；冲突结论在扩展集复核；A4–A15 配比建模，A6–A11 检验、A12–A15 外推，配比与 Loss 成对；跨体系映射参考 A16 并说明假设。
- Q2：经典标度律以 B1 为主要拟合数据；B2 或 B3 验证；B4 与 B5 跨族或文献验证；B6 或 B7/B8 支持质量部分；B9、B10 支持百亿参数以上外推讨论。B6–B8 半合成数据不得称为直接观测。通过 Q1 输出引入附件 A 信息，不重复读取 A 原始文件。
- Q3：至少三个数量级预算；题面建议 10^19、10^22、10^24 FLOPs。比较质量成本函数影响；定义并检验结构性转移，不预设一定存在；C7 支持上下文取值；解析临界长度并做敏感性分析；三项成本默认使用同一 D。
- Q4：C1 或 C2，加 C3；使用 C4 的算力、数据量、开放权重等字段；对 C8 至少做一项逐任务聚合，不能只用汇总表；说明开放性、pretrained/chat/finetuned 分类及时间口径；C6 或 C5 桥接须区分可比性等级并分析映射误差。

## 主要风险

数据源与模型族间 Loss 口径可能不同；质量域与训练域分类不同；参数可能不可识别；外推依赖半合成补充数据；时间趋势不能自动解释为因果技术进步。以上都需在审计和验证中处理，不可先写结论再找证据。
