# F 题原始附件独立审计（2026-09-24）

本次按用户要求检查工作区 `F题/` 原始资料，只找问题，不修改数据或重建模型。以下结论来自实际读取和跨文件核验，不使用历史 PDF 隐藏文字。不能凭异常认定有人恶意篡改或归因于组委会。

## 最优先处理的发现

### 1. B8 的 Q 方向与 B6/B7 冲突，不能混合拟合

位置：`B_scaling_laws/supplementary_NQ_experiment_large.csv`。

- 1,704 行，150 个固定 `(N_params_B,D_tokens_B)` 分组。按 Q 升序，相邻 Loss 差分中 **1,311 次上升、2 次下降、241 次相等**。
- B6 的同类统计为 80 次上升、235 次下降；B7 为 102 次上升、303 次下降。B6/B7 有噪声，不能要求每一步下降，但 B8 的整体方向明显相反。
- B8 的例子：N=0.07B、D=5B，Q 从 0.05 到 0.9，Loss 从 1.0401 增至 3.0925。
- B6 与 B8 有 160 组相同 N/D/Q，**160 组 Loss 全不相同**，最大差 2.5769；B7 与 B8 的 224 组重合设计也全部不一致。
- B8 另有 **362 行 Loss 恰为 0.5**，呈现明显下限堆积；仅凭数据不能证明具体生成公式。

影响：直接拼接会把“更好的质量降低损失”的解释翻转，污染 Q2 的质量效应和 Q3 的最优配置。现有附件没有给出足够的 B8 生成代码或字段说明来消除这一冲突。

建议 cyj：主分析选择题面允许的 B6 或 B7；B8 单列为存在方向/口径冲突的敏感性资料。不要擅自改成 `1-Q`，也不要反推其生成公式后当作真实规律。B6–B8 都是半合成补充数据。

### 2. C3 历史行的 Average 不是现有六维得分均值

位置：`C_efficiency_evolution/leaderboard_extended_timeseries.csv`。

- 4,599 行中，26 行标注 `Historical (papers/reports)`，其 **26 行全部**与六维算术均值相差超过 0.01。
- CSV 第 3 行 GPT-3 (175B)：`Average=50`，六项得分是 29.2、14.3、0、0、0、2.5，均值 **7.6667**。
- 相比之下，C1 的全部 4,576 行 Average 与六维均值一致（最大浮点差约 1.42e-14）。
- C3 另有 4,573 条榜单记录，不能和 26 条历史记录默认视为同一测量尺度。其榜单 Average 保留两位小数，正常舍入不应误报成矛盾。

建议 zhh：C3 仍按题面使用，但历史子集需单列来源、说明口径不可比，并做纳入/排除敏感性。不能将历史行的零值未经确认解释成真实零能力，也不能把重算均值当作已修复真实历史评测。不能将两类 Average 直接拼成连续、可比的技术进步曲线。

### 3. A1 和 A2/A3 不独立，B6 和 B7 也不独立

- A1 全部 1,419 条 arxiv 样本在 A2 中出现；A1 全部 10,000 条 github 样本在 A3 中出现。ID 和 22 个质量信号均一致。
- 三个文件合计 272,505 条记录，但仅 **261,086 个不同 ID**。题面“处理全部记录”不等于聚合时把重合样本加权两次。
- B7 包含 B6 的全部 360 组 N/D/Q，Loss 完全相同；不能将 B6 拟合、B7 验证称为独立外部验证。
- A 的两个外推配方表各 63 行，都是训练配方子集；1M 和 60M 检验表共用全部 256 个配方。后者适合跨规模比较，但不能当成 512 个独立配方。

建议 chm/cyj：保留来源标签，聚合时明确去重/权重，验证按样本 ID、配方或模型轨迹分组，防止泄漏。抽样集和扩展集对照应报告重合情况。

### 4. A 的质量指标有非有限值和尺度陷阱

- A1 的 18 条记录含非有限质量向量：`modernbert_reasoning` 13 条、`modernbert_professionalism` 5 条，共 108 个非有限元素。
- A3 的第 188,215 条记录，`modernbert_professionalism` 的 6 个元素均非有限。
- 具体行号和 ID 全列于 `targeted.json`。Python 默认 JSON 解析能接受这些特殊数值，并不意味着可直接参与均值、标准化或概率变换。
- 多个名称带 fraction/frac 的字段实际落在 0–100 量级；top-2gram/top-3gram 甚至超过 100。A1 分别 2/2 个超界单元格，A3 分别 7/9 个，A3 最大值为 194/284。
- 8 个列表型指标并非同一尺度：长度分别有 1、2、4、6，元素可为负数或大于 1。因此不能把所有列表直接当概率、统一取平均，或者仅凭字段名将所有值截断到 [0,1]。
- `fineweb_edu` 也出现负值；DSIR 为大幅负数。负数本身不等于错误，须先确认分数语义与转换规则。
- A1 各域样本数极不均衡：book 171、arxiv 1,419、commoncrawl 9,640，其他四域各 10,000；直接平均会隐含这些采样权重。

建议 chm：显式检测有限值、记录缺失处理，按字段语义定尺度；异常值保留证据和敏感性处理。对比例超界先查口径，不要默认按真实百分比解释。不得按“看起来能跑”统一补零。

## 其他会误导结论的风险

### 5. 同名模型不是唯一连接键，评分列也有不同口径

- C1：4,576 行但只有 4,497 个不同模型名，79 个名字各出现两次。只按 Model 连接 C1/C3 会得到 4,731 行，产生重复加权和假冲突。
- C6 的 75 行与 C1 仅按 Model 连接会变成 81 行；逐模型寻找相同 Average 时，75 行都能找到匹配记录。不能把多对多连接产生的差异自动当成桥接数据错误。
- Parquet 是 4,576×36，`Model` 含 HTML 链接；直接连接 C1 的 Model，匹配数为 **0**。`fullname` 与 C1 的模型名及行序完全一致，六维分数逐行核验全部相同。
- Parquet 同时含 `Raw` 和处理后的榜单分数。例如第一行 BBH Raw=0.35962543，BBH=10.05552508；GPQA Raw=0.25922819，GPQA=1.23042506。并非统一乘 100。
- C8 含任务指标、子任务指标和不同聚合层级，不能把所有数值字段求均值。逐任务日志与榜单还需核对评测版本和 precision。
- Parquet 有 1 行 Flagged=true，该字段未包含于 cleaned CSV；应明确是否采用标记筛选。

建议 zhh：优先使用可追踪的评测标识/版本/精度，核验 join 的基数；区分原始分数与归一化得分，不能静默混用。

### 6. 开源、发布时间、参数量和 Loss 来源不可默认可靠

- B9 的 132 行中，明确标注开放权重的只有 66 行；另有 Unreleased 35、API access 21、Hosted access 8、缺失 2。不能因为资料说明概称“开源大模型”，就把全部 B9 当开源样本。
- C1 的许可证缺失 **1,753/4,576**，参数量缺失 3、零值 7，Submission Date 缺失 12。缺失许可证不等于允许研究复现，零参数也不能进入 log(N)。
- C2 只有 447 行有 Epoch 发布时间；发布日期、榜单提交日不能无说明混成同一时间轴。
- C4 缺训练计算量 2,133/3,523、训练数据量 2,099/3,523。缺失并不适合自动补零，完整案例筛选也可能改变样本构成。
- C6 高可比桥接只有 **7** 行，另外 68 行为不同验证集的近似 Loss，且 D 缺失 68 行。不能把 75 个 Loss 当成同一验证集精确观测。
- B4 的 Pythia 行与 B1 近邻 Loss 有明显差距。例如 B4 N=0.07B、D=6B、Loss=4.3629；B1 N=0.070542B、D=6.291B、Loss=3.3024。参数与数据量并非严格相等，这不是同点矛盾的证明，但足以要求核查验证集和收敛口径，不能作为同分布独立盲测。
- B1 每个模型的 precision 同时出现 fp16/bf16、wd 有 69–76 个不同值，而 lr 和 step_time_ms 各只有一个值。未核验辅助字段的来源前，不能据此解释精度、学习率或正则化的因果作用；这一现象不证明核心 Loss 是伪造的。

### 7. 文件损坏、计量和文档细节

- C8 共 1,958 个 JSON，4 个截断；1,860/1,863 个模型目录至少有一个可解析文件。损坏路径见 `evidence.json`。不能尝试猜补截断尾部后当作原始观测。
- 7 个 Pythia eval_details 目录只有 README，可见示例和摘要不等于齐全的逐任务数据。
- A 配方均非负、index 唯一、与 Loss 成对的 index 顺序一致，但行和范围包括 0.996–1.003。单纯形处理需容忍舍入并记录归一化。
- B 的单位换算为 `C_FLOPs_1e21 ≈ 0.006 * N_params_B * D_tokens_B`。B1 全部偏差不超过 0.00005，可由 C 的四位小数舍入解释；小算力行比值偏离较大，不能据此认定异常。B2 比值中位数为 1、范围约 0.9887–1.0240，但属于半合成。
- B3 为插值轨迹、B2 为校准半合成、B10/A12–A15 的 Loss 为估算/外推。题面要求使用，不等于允许把它们当独立真实实验。
- published_scaling_data.csv 实际 44×6，说明表写 44×5；应以实际表头为准。字段拼写如 `qurater`、`rps_lines_ending_with_terminal_punctution_mark` 应以实际键为准。
