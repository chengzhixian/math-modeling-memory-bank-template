# 远程 main 模型指标与质量评价

审查日期：2026-09-26（北京时间）。对象：`chengzhixian/math-modeling-memory-bank-template` 的远程 `main@c6b36c08b5a85c81a3889d48d50c26ac136a048b`。

总体判断：Q1 在 1M 配比预测上有实际效果，跨规模更适合作排序代理；Q2 的同源 N/D 拟合非常强，质量项在半合成数据上有效，但完整四变量桥接未获得实证标定；Q3 求解与算式一致，现实最优性尚未验证；Q4 的前沿时间预测表现较弱，未来结果只能作明示假设的情景。不能用 Q2 的近乎完美 R² 为整套模型背书。

## A. 范围、版本和指标口径

- 开始时执行 fetch 与 ls-remote，二者指向同一 main SHA。原工作目录在 `review/q3-v7-20260925`，有未提交审计目录，本轮未操作这些内容。

- 数据说明仅采用 `problem/readable/DATA_DESCRIPTION_VISIBLE.md`，并从当前题面 DOCX 核对四问要求。当前清理 PDF 的哈希、页数、无文本层检查通过。隐藏文字、作废 Gemini 提交、隔离资料均未用作推理依据。
- R² 为 `1−Σ(y−预测)²/Σ(y−本组均值)²`；相对误差统一为 **MAPE=100×平均(|预测−实际|/|实际|)**。MAPE 不是有符号误差，也不是 RMSE/均值。
- Q1 先逐目标域计算，再取 13 域中位数。没有将不同目标域的 Loss 合并得到一个可能虚高的整体 R²。
- Q2 B1 全样本、B7 冻结嵌套外层预测、Q4 滚动预测和来源内 LOO 为本轮复算；Q1 嵌套 OOF 的 R²由发布的整组 OOF RMSE 与原始目标方差恢复。B1 留一规模/Token-tail 指标引用已发布记录，本轮没有重新执行全部非线性重拟合。
- 未重跑全部 A1–A3 评分、全部优化全局证书、全部历史实验、官方网站核验或论文 PDF 编译。本轮结论不包含这些范围的新增验收。

Q1 跨规模行专门检验冻结 1M 模型的**原始绝对输出**，没有用检验组重新拟合截距或尺度，也不是 Q2 的完整条件公式。main 本已限定它用于相对配比/排序；上述结果暴露该限制，不应误称新增代码错误。60M/1B 的 13 个目标 R²全部为负。1M 检验各目标 R²范围为 0.4280–0.8178。

Q1 10B/70B 估算表的排序 Spearman 中位为 0.4915/0.3941；冻结原始输出 MAPE 中位为 201.69%/284.71%。这些不是实测外部误差。两个估算组各 63 个配方全部来自 A4；它们对无条件跨规模推荐提供负向压力证据。

Q2 B7 无质量项对照 R²=0.629630、MAPE=6.2333%、RMSE=0.207307。加入质量项后的 RMSE 降约 76.6%，表明质量项在该半合成来源内有贡献。B7 的 240/450 行超出 B1 正式共同 N/D 支持域，不能把全表 CV 包装成全部在正式域内的独立验证。

Q4 后训练可部署常数对照 RMSE=3.736621 分，q90 模型降约 41.1%。负 R²表示低于**回测目标均值**这个事后常数参照，不意味着它低于每一种可部署基线。只有四个重叠窗口，时间外推证据很短。

## C–D. 发现、影响与处理建议

本轮未发现会推翻**已声明条件范围**的新计算 BLOCKER。若将当前模型发布为“真实跨附件四变量普适模型、无条件真实训练最优或已验证长期能力预测”，则存在科学结论 BLOCKER：缺成对标定和独立真实验证。解决方式是维持条件声明，或补同训练体系 N/D/Q/p 与共同验证 Loss 的控制实验后重新标定、检验和优化。
