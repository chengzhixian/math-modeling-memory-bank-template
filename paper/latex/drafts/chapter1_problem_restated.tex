\section{问题重述}

\subsection{问题背景}

大语言模型的训练需要确定参数规模、训练数据量及计算投入。模型对验证文本的预测表现通常以交叉熵损失（Loss）衡量，实际能力还需通过多项下游任务的评测得分考察。有限算力下，如何组织训练数据与配置计算资源，是提升模型能力时需要共同考虑的问题。

已有标度关系主要描述参数量、数据量与 Loss 的联系，但训练数据还存在质量和领域组成差异：质量指标可能对同一文本作出相反评价，不同领域的训练占比也可能产生不同的损失响应。提高数据质量和处理更长上下文均会消耗算力。参数扩张、数据投入、质量提升与上下文需求受同一预算制约，而 Loss 变化又不能直接等同于下游能力变化，这构成资源配置与能力评价中的主要矛盾。

题目提供质量信号与配比实验、训练轨迹及标度律补充数据、模型架构与能力评测资料，其中部分数据为半合成或估算结果。研究需区分其来源和适用范围，刻画质量与配比的作用，将其与规模效应联系起来，求解受算力约束的配置问题，并借助历史评测考察能力演进及未来前沿。具体任务按以下四问展开。

\subsection{问题提出}

\noindent\textbf{问题一：}针对训练语料质量与领域配比，使用附件 A 抽样集及两个扩展集的全部质量信号，统一 22 项指标的优劣方向，构建质量评分，说明样本评分的聚合方式，给出扩展集域级评分并与抽样结果对照；定义同一文本的指标评价冲突，分析成因、建立消解规则，并在扩展集检验主要结论。再利用成对的配比与 Loss 数据，刻画满足非负且和为一的 17 域配比及领域组合对损失的影响；如引入质量评分，须说明两套领域体系的关联依据。最终在指定检验集验证关系，并利用外推表讨论结论的稳健性。

\noindent\textbf{问题二：}以问题一所得质量评分和配比信息为输入，结合附件 B 的训练轨迹与补充资料，建立同时反映参数规模、数据量、质量和配比的广义标度关系。由于附件 A、B 的实验独立且损失口径需要衔接，应提出可检验的跨来源假设，并区分真实观测、半合成及估算数据的证据范围。以指定训练日志为主要拟合依据，完成轨迹、跨模型族及文献数据的验证，讨论大模型尺度的外推；估计并检验模型参数，分析各因素的边际效用、弹性、领域间替代或互补关系，以及质量提升与规模扩大可相互替代的条件。

\noindent\textbf{问题三：}在前两问结果基础上，针对至少三个不同数量级的算力预算，求解使预测 Loss 降低的参数量、训练数据量、质量及领域配比配置，并说明配比作为决策变量或既定输入的依据。总成本须计入基础训练、质量提升及长上下文注意力开销，三者默认对应同一训练数据量；上下文长度依据附件 C 的架构资料外生给定。比较质量成本函数的选择对配置的影响，明确定义并识别预算变化时可能出现的结构性转移；解析求出注意力开销与训练开销相当的临界上下文长度，并在可行范围内分析配置的敏感性。

\noindent\textbf{问题四：}结合附件 C 的排行榜、时序记录、模型元数据与逐任务评测结果，明确综合能力指标、开放模型筛选规则、模型类型和时间口径，建立能力演进分析，分别量化规模扩张与非规模技术进步的贡献占比。在算力增长放缓的情景下，预测未来 12 个月或 24 个月开源模型的能力前沿并评估不确定性。同时利用分级可比的桥接数据或可核验文献，建立前三问所用 Loss 与多维评测得分之间的联系，分析映射误差对贡献分解和前沿预测的影响。

四问依次由数据质量与配比关系、广义标度关系推进至预算配置，再以能力评测检视配置结果及历史演进；各环节需明确跨数据源和跨指标衔接的适用边界。
