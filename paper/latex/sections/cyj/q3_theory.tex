\subsection{目标函数、约束与理论分析}

令 $N,D$ 分别以十亿参数和十亿 token 计，$L_{\rm ctx}$ 为外生上下文长度。对质量成本族 $g$、基准质量 $Q_0$，题面给出的总 FLOPs 可写为
\begin{equation}
C(N,D,Q;L_{\rm ctx})=6\times10^{18}ND
+10^{9}D[g(Q)-g(Q_0)]_+
+2\times10^{14}NDL_{\rm ctx}.
\end{equation}
条件诊断考察指数、幂函数和对数三种质量成本族。除已记录的 2048、8192、131072 token 外，新增 4096、16384、24576、30000、32768、49152、65536 token 作为 CYJ 外生敏感性情景，不能视为 C7 新观测。预算作为约束 $C\leq C_{\max}$，$N\in[.07,11.97]$、$D\in[10,600]$、$Q\in[Q_0,1]$。$Q=Q_0$ 处正部函数可能不光滑，使用右导数检查向可行域内部增加 Q 的条件。

在固定 B7 半合成 Loss 坐标下，联合拟合的双交互候选给出
\begin{align}
L_N&=-\alpha AN^{-\alpha-1}+(1-Q)G_N/N,\\
L_D&=-\beta BD^{-\beta-1}+(1-Q)G_D/D,\\
L_Q&=-G_0-G_N\ln N-G_D\ln(D/100).
\end{align}
记 $a(L_{\rm ctx})=6\times10^{18}+2\times10^{14}L_{\rm ctx}$。在 $Q>Q_0$，成本偏导为
\begin{align}
C_N&=a(L_{\rm ctx})D,\\
C_D&=a(L_{\rm ctx})N+10^9[g(Q)-g(Q_0)],\\
C_Q&=10^9Dg'(Q).
\end{align}
指数族的 $g''>0$、幂族的 $g''>0$，而对数族的 $g''<0$；质量边际成本随 Q 的方向因此不同，必须结合 $L_Q$ 和可行边界判断配置。训练与 attention 成本之比为 $1:L_{\rm ctx}/30000$，等成本长度为 30000 token；该等成本点不自动等于优化活跃约束的转变点。

给定预算和 $L_{\rm ctx}$，条件实验求 $\min_{N,D,Q}\widehat L_B$。内点且预算约束激活时，$R_x=-L_x/C_x$ 对 $x=N,D,Q$ 相等，等于预算乘子 $\lambda$。在下界，必要条件为 $R_x\leq\lambda$；在上界，$R_x\geq\lambda$。预算松弛时 $\lambda=0$；若三个 Loss 梯度仍负，解落在支持域上界属于\emph{支持域截断}，不代表真实最优策略不需要更多资源。数值求解记录预算利用率、原始可行性与 KKT 相对残差；KKT 仅为必要条件。条件预测区间应随每个场景计算，但同源经验覆盖率不能直接转写为正式最优配置的覆盖率。

配比 $\boldsymbol p$ 只保留 A 侧 1M、13 个 target 的对比向量，可比较明示权重、minimax 或目标保护约束等敏感性情景，但不与 B7 Loss 直接相加。这里的 attention 成本系数属于题面定义，不能与历史已撤回的跨规模 Loss 迁移参数混淆；也不使用无证据的 Loss 换算系数。故本节的接口政策为 \texttt{p\_policy=sensitivity\_only}，\texttt{ready\_for\_Q3=false}。本节实验只能表述为 B7 条件模型下的资源配置诊断。

以 $Q_0=0.5$ 为明确情景，11 档预算、10 档上下文及 3 种质量成本族形成 330 个网格点；321 点在给定支持域可行并通过求解器的可行性与 KKT 数值检查，9 点的预算低于支持域内最低成本。可行点中 81 点已同时达到 $N,D,Q$ 上界且预算未用尽，属于支持域截断。其余点分别有 237 个预算激活并触及至少一个变量界、3 个预算激活的内点。以 30000 token、指数成本族为例，数值扫描把 $Q=1$ 的激活预算夹在约 $(1.1615,1.1688)\times10^{20}$ FLOPs，把全部支持域上界激活夹在约 $(8.7998,8.8554)\times10^{22}$ FLOPs。转变点只是在本模型、求解器容差和边界标记规则下的数值括区，不能解释为真实系统的普适阈值。
