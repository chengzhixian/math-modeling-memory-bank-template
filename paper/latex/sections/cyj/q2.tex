\section{问题二：分层标度关系与可识别性}

\subsection{附件角色与统一坐标的边界}

我们先按来源和生成方式固定数据角色。B1 的 1176 条 Pythia 轨迹记录用于同源 $N$--$D$ 基线；B2 为半合成 Cerebras 轨迹，B3 为插值轨迹，只用于形状检查。B2 的 7 条、B3 的 8 条轨迹首尾 Loss 均下降；它们不是独立真实外测。B4 的 57 个跨族收敛点和 B5 的 44 个文献整理点，在各自同家族、同来源的规模支配配对中，下降方向分别符合 131/133、113/113 对；这只是描述性方向验证。尚不能证明它们与 B1 使用相同 tokenizer、验证语料、对数底和聚合定义，因此不计算统一的外部 RMSE。B6 的 360 点全部包含在 B7 的 450 个 $N,D,Q$ 坐标中，两表不互作独立检验。B8 含 calibrated 与 extrapolated 标签，质量方向和损失水平与 B7 冲突，单独审计。B9 是大模型元数据，B10 是 estimated Loss，仅作为大规模外推的压力参考，不能当真实独立测试。详细计数及输入身份见源别验证表。

全文取 $N$ 的单位为十亿参数，$D$ 的单位为十亿 token。$Q_{\rm score}$ 为 B 侧原生半合成质量坐标，问题一的 $Q_A$ 是 A 侧质量代理；附件没有成对标定样本。问题一配比 $\boldsymbol p$ 对应 17 域单纯形，其可核验输出是 1M 条件下 13 个目标域的相对 Loss 对比，并非 B1 或 B7 的总体 \texttt{val\_loss}。

\subsection{B1 同源 $N$--$D$ 经验基线}

在 B1 的范围 $N\in[0.070542,11.965825]$、$D\in[0.134,299.893]$ 内，采用待检验的经验式
\begin{equation}
\widehat L_{B1}(N,D)=E+A N^{-\alpha}+B D^{-\beta}.
\end{equation}
以 8 个规模组等权、对数 Loss 残差的 Huber 目标和正参数约束估计得到
$E=1.689838$、$A=0.353969$、$B=1.240275$、$\alpha=0.339985$、$\beta=0.279892$。
全样本 RMSE 为 $1.4658\times10^{-4}$；留一规模组均值为 $1.4613\times10^{-4}$；每组后 30\% token 检查点留出的 RMSE 为 $1.1600\times10^{-4}$。去除 $E$、$N$ 或 $D$ 项均明显损害 B1 同源重构。

上述接近确定性的精度触发来源审查。B1 的 $D$ 与训练步数乘每步 $2{,}097{,}152$ token 的显示舍入相容，\texttt{ppl} 与 $\exp(\texttt{val\_loss})$ 的显示舍入也全行相容；但本附件缺少逐检查点原始评估记录和生成脚本，尚不能判断 \texttt{val\_loss} 是否经插值、平滑或共同公式构造。因此这里只主张\emph{B1 同源数据上的条件经验重构}，不以极低残差推断真实跨源预测精度。

\subsection{B7 原生质量关系及冻结主候选}

B7 的原生支持为 $N\in[0.07,11.97]$、$D\in[10,600]$、$Q_{\rm score}\in[0.1,1]$。已发布的诊断基线为
\begin{equation}
\widehat L_{B7}=E_7+A_7N^{-\alpha_7}+B_7D^{-\beta_7}+G(1-Q_{\rm score}),
\end{equation}
其 $\partial\widehat L_{B7}/\partial Q_{\rm score}=-G$ 恒定。对 45 个固定 $(N,D)$ 组分别以组内十个 Q 点回归，斜率范围为 $[-0.6072,-0.1931]$，对恒定斜率的组级 RMSE 为 $0.1078$。用 $\log N$ 与 $\log D$ 描述这些斜率的回归 $R^2=0.8601$；这只描述半合成网格，不是质量的因果机制。

早期同源分组比较显示双交互优于恒定 $G$：旧两阶段双交互与恒定项的平均 RMSE 在 N 留级为 $0.05194$ 对 $0.05823$，D 留级为 $0.05021$ 对 $0.05709$，Q 留级为 $0.05006$ 对 $0.05762$。候选形式在此前的全 B7 诊断后提出，这些分数只是探索性选型证据；下文另以五族嵌套外留级评估联合拟合族。恒定 $G$ 保留为诊断基线，不将交互参数当已验证真实质量规律。

据此固定 B7 的主\emph{候选}族，不再扩展函数族：
\begin{align}
\widehat L_B&=E+AN^{-\alpha}+BD^{-\beta}+(1-Q)G(N,D),\\
G(N,D)&=G_0+G_N\ln N+G_D\ln(D/100).
\end{align}
旧接口先从无质量模型估计两个指数，再固定指数对其余系数做线性回归。该两阶段估计不是八参数的联合最小二乘。本文重新以解析参数 Jacobian、正幅度与正指数边界、$G$ 四角正性约束做多起点联合最小二乘；在每一留出折内也独立重估全部自由参数。完整 B7 的联合拟合为
\begin{align*}
(E,A,B)&=(1.73538614,\ 0.35758295,\ 1.26537325),\\
(\alpha,\beta)&=(0.33926681,\ 0.32039457),\\
(G_0,G_N,G_D)&=(0.37014726,\ -0.05949206,\ -0.01580520).
\end{align*}
$G$ 在声明矩形支持域的四角最小值为 $0.19414484>0$，故该拟合的 $\partial\widehat L_B/\partial Q=-G<0$ 在域内成立。联合拟合 12 个起点全部收敛至近同一解，扩大搜索边界后参数基本不变；这不证明全局唯一。

\subsection{嵌套留级检查、识别性与经验不确定性}

联合拟合全样本 RMSE 为 $0.048410$，低于旧两阶段方案的 $0.049188$。同一固定族、24 折的留级平均 RMSE 为
\begin{align*}
&\text{联合：N }0.049764,\quad\text{D }0.049008,\quad\text{Q }0.049352;\\
&\text{两阶段：N }0.051936,\quad\text{D }0.050207,\quad\text{Q }0.050061.
\end{align*}
考虑训练和三轴留出、12 起点收敛及扩大搜索界后的稳定性，本节以联合拟合作条件分析；旧参数只供历史 v3 接口复现。

另在外层留一个 N、D 或 Q 等级时，只用外层训练部分完成五个函数族的内层选择。24 折中双交互被选中 23 折，单 $\log N$ 交互被选中 1 折；三轴 pooled 外层 RMSE 为 $0.050070$、$0.050039$、$0.049697$，MAE 为 $0.038994$、$0.038903$、$0.038709$。完整 B7 曾参与候选族构思，所以这些仍是半合成同源条件泛化，不能称未触碰的真实训练外测。局部参数 Jacobian 满秩，但 $A$ 与 $\alpha$ 的工作相关系数约 $-0.964$；200 次 $(N,D)$ 簇重抽虽均成功，也不能令这些系数获得独立物理解释。

外层训练部分的内层 OOF 绝对残差分位数产生对称经验区间，不读取该外层留出观测来调宽度。80/90/95\% 名义区间的三轴外层覆盖分别为 $(.80,.80,.80)$、$(.90,.89,.90)$、$(.96,.95,.95)$；95\% 平均宽约为 $0.20/0.19/0.19$ B 原生 Loss。但逐组最低 95\% 覆盖仅为 $0.84$（留 $N=0.07$）、$0.88$（留 $D=10$）、$0.89$（留 $Q=1$），不能声称每个支持域子群都达到名义水平。该方法与历史 v3 的 500 次两阶段参数 bootstrap 区间及新 v4 的 bootstrap 加残差区间不同，不能直接替它们标注已校准；折间相关且支持域为半合成网格，也没有真实训练覆盖保证。

\subsection{边际效用、弹性与替代关系}

在输入单位为十亿参数、十亿 token 和 B 原生 Q 分数时，三偏导为
\begin{align}
L_N&=-\alpha AN^{-\alpha-1}+(1-Q)G_N/N,\\
L_D&=-\beta BD^{-\beta-1}+(1-Q)G_D/D,\\
L_Q&=-G(N,D).
\end{align}
为把改善写成正数，定义弹性 $\varepsilon_x=-xL_x/L$，$x=N,D,Q$，均无量纲。例如 N 提高 1\% 时，Loss 的局部相对降幅约为 $\varepsilon_N$\%；旧 v3 接口返回的是带符号 $xL_x/L$，其语义保持历史不变。固定 $L,D$ 得 $dN/dQ=-L_Q/L_N$；固定 $L,N$ 得 $dD/dQ=-L_Q/L_D$，在本拟合支持域内均为负。有限替代对给定 $Q_1$ 在 N 或 D 声明边界内解等损失方程；无根时明确标记，不把替代曲线延伸到域外。交叉导数 $L_{NQ}=-G_N/N$、$L_{DQ}=-G_D/D$ 只描述拟合曲面的质量与规模交互，不是干预效应。
