\section{问题二：分层标度关系与可识别性}

\subsection{附件角色与统一坐标的边界}

我们先按来源和生成方式固定数据角色。B1 的 1176 条 Pythia 轨迹记录用于同源 $N$--$D$ 基线；B2 为半合成 Cerebras 轨迹，B3 为插值轨迹，只用于形状检查。B4 的 57 个跨族收敛点和 B5 的 44 个文献整理点尚不能证明与 B1 使用相同 tokenizer、验证语料、对数底和聚合定义，因此不计算统一的外部 RMSE。B6 的 360 点全部包含在 B7 的 450 个 $N,D,Q$ 坐标中，两表不互作独立检验。B8 含 calibrated 与 extrapolated 标签，质量方向和损失水平与 B7 冲突，单独审计。B9 是大模型元数据，B10 是 estimated Loss，仅作为大规模外推的压力参考，不能当真实独立测试。

全文取 $N$ 的单位为十亿参数，$D$ 的单位为十亿 token。$Q_{\rm score}$ 为 B 侧原生半合成质量坐标，问题一的 $Q_A$ 是 A 侧质量代理；附件没有成对标定样本。问题一配比 $\boldsymbol p$ 对应 17 域单纯形，其可核验输出是 1M 条件下 13 个目标域的相对 Loss 对比，并非 B1 或 B7 的总体 \texttt{val\_loss}。

\subsection{B1 同源 $N$--$D$ 经验基线}

在 B1 的范围 $N\in[0.070542,11.965825]$、$D\in[0.134,299.893]$ 内，采用待检验的经验式
\begin{equation}
\widehat L_{B1}(N,D)=E+A N^{-\alpha}+B D^{-\beta}.
\end{equation}
以 8 个规模组等权、对数 Loss 残差的 Huber 目标和正参数约束估计得到
$E=1.689838$、$A=0.353969$、$B=1.240275$、$\alpha=0.339985$、$\beta=0.279892$。
全样本 RMSE 为 $1.4658\times10^{-4}$；留一规模组均值为 $1.4613\times10^{-4}$；每组后 30\% token 检查点留出的 RMSE 为 $1.1600\times10^{-4}$。去除 $E$、$N$ 或 $D$ 项均明显损害 B1 同源重构。

上述接近确定性的精度触发来源审查。B1 的 $D$ 与训练步数乘每步 $2{,}097{,}152$ token 的显示舍入相容，\texttt{ppl} 与 $\exp(\texttt{val\_loss})$ 的显示舍入也全行相容；但本附件缺少逐检查点原始评估记录和生成脚本，尚不能判断 \texttt{val\_loss} 是否经插值、平滑或共同公式构造。因此这里只主张\emph{B1 同源数据上的条件经验重构}，不以极低残差推断真实跨源预测精度。

\subsection{B7 原生质量关系及冻结主候选}

B7 的原生支持为 $N\in[0.07,11.97]$、$D\in[10,600]$、$Q_{\rm score}\in[0.1,1]$。已发布的诊断基线为
\begin{equation}
\widehat L_{B7}=E_7+A_7N^{-\alpha_7}+B_7D^{-\beta_7}+G(1-Q_{\rm score}),
\end{equation}
其 $\partial\widehat L_{B7}/\partial Q_{\rm score}=-G$ 恒定。对 45 个固定 $(N,D)$ 组分别以组内十个 Q 点回归，斜率范围为 $[-0.6072,-0.1931]$，对恒定斜率的组级 RMSE 为 $0.1078$。用 $\log N$ 与 $\log D$ 描述这些斜率的回归 $R^2=0.8601$；这只描述半合成网格，不是质量的因果机制。

早期同源分组比较显示双交互优于恒定 $G$：旧两阶段双交互与恒定项的平均 RMSE 在 N 留级为 $0.05194$ 对 $0.05823$，D 留级为 $0.05021$ 对 $0.05709$，Q 留级为 $0.05006$ 对 $0.05762$。候选形式在此前的全 B7 诊断后提出，这些分数只是探索性选型证据；下文另以五族嵌套外留级评估联合拟合族。恒定 $G$ 保留为诊断基线，不将交互参数当已验证真实质量规律。

据此固定 B7 的主\emph{候选}族，不再扩展函数族：
\begin{align}
\widehat L_B&=E+AN^{-\alpha}+BD^{-\beta}+(1-Q)G(N,D),\\
G(N,D)&=G_0+G_N\ln N+G_D\ln(D/100).
\end{align}
旧接口先从无质量模型估计两个指数，再固定指数对其余系数做线性回归。该两阶段估计不是八参数的联合最小二乘。本文重新以解析参数 Jacobian、正幅度与正指数边界、$G$ 四角正性约束做多起点联合最小二乘；在每一留出折内也独立重估全部自由参数。完整 B7 的联合拟合为
\begin{align*}
(E,A,B)&=(1.73538614,\ 0.35758295,\ 1.26537325),\\
(\alpha,\beta)&=(0.33926681,\ 0.32039457),\\
(G_0,G_N,G_D)&=(0.37014726,\ -0.05949206,\ -0.01580520).
\end{align*}
$G$ 在声明矩形支持域的四角最小值为 $0.19414484>0$，故该拟合的 $\partial\widehat L_B/\partial Q=-G<0$ 在域内成立。联合拟合 12 个起点全部收敛至近同一解，扩大搜索边界后参数基本不变；这不证明全局唯一。

\subsection{嵌套留级检查、识别性与经验不确定性}

联合拟合全样本 RMSE 为 $0.048410$，低于旧两阶段方案的 $0.049188$。同一固定族、24 折的留级平均 RMSE 为
\begin{align*}
&\text{联合：N }0.049764,\quad\text{D }0.049008,\quad\text{Q }0.049352;\\
&\text{两阶段：N }0.051936,\quad\text{D }0.050207,\quad\text{Q }0.050061.
\end{align*}
考虑训练和三轴留出、12 起点收敛及扩大搜索界后的稳定性，本节以联合拟合作条件分析；旧参数只供历史 v3 接口复现。

另在外层留一个 N、D 或 Q 等级时，只用外层训练部分完成五个函数族的内层选择。24 折中双交互被选中 23 折，单 $\log N$ 交互被选中 1 折；三轴 pooled 外层 RMSE 为 $0.050070$、$0.050039$、$0.049697$，MAE 为 $0.038994$、$0.038903$、$0.038709$。完整 B7 曾参与候选族构思，所以这些仍是半合成同源条件泛化，不能称未触碰的真实训练外测。局部参数 Jacobian 满秩，但 $A$ 与 $\alpha$ 的工作相关系数约 $-0.964$；200 次 $(N,D)$ 簇重抽虽均成功，也不能令这些系数获得独立物理解释。

外层训练部分的内层 OOF 绝对残差分位数产生对称经验区间，不读取该外层留出观测来调宽度。80/90/95\% 名义区间的三轴外层覆盖分别为 $(.80,.80,.80)$、$(.90,.89,.90)$、$(.96,.95,.95)$；95\% 平均宽约为 $0.20/0.19/0.19$ B 原生 Loss。但逐组最低 95\% 覆盖仅为 $0.84$（留 $N=0.07$）、$0.88$（留 $D=10$）、$0.89$（留 $Q=1$），不能声称每个支持域子群都达到名义水平。该方法与历史 v3 的 500 次两阶段参数 bootstrap 区间及新 v4 的 bootstrap 加残差区间不同，不能直接替它们标注已校准；折间相关且支持域为半合成网格，也没有真实训练覆盖保证。

\subsection{边际效用、弹性与替代关系}

在输入单位为十亿参数、十亿 token 和 B 原生 Q 分数时，三偏导为
\begin{align}
L_N&=-\alpha AN^{-\alpha-1}+(1-Q)G_N/N,\\
L_D&=-\beta BD^{-\beta-1}+(1-Q)G_D/D,\\
L_Q&=-G(N,D).
\end{align}
为把改善写成正数，定义弹性 $\varepsilon_x=-xL_x/L$，$x=N,D,Q$，均无量纲。例如 N 提高 1\% 时，Loss 的局部相对降幅约为 $\varepsilon_N$\%；旧 v3 接口返回的是带符号 $xL_x/L$，其语义保持历史不变。固定 $L,D$ 得 $dN/dQ=-L_Q/L_N$；固定 $L,N$ 得 $dD/dQ=-L_Q/L_D$，在本拟合支持域内均为负。有限替代对给定 $Q_1$ 在 N 或 D 声明边界内解等损失方程；无根时明确标记，不把替代曲线延伸到域外。交叉导数 $L_{NQ}=-G_N/N$、$L_{DQ}=-G_D/D$ 只描述拟合曲面的质量与规模交互，不是干预效应。

\subsection{A 侧配比敏感性政策}

问题一的 17 域配比只提供 13 个目标域在 1M 条件下的局部对比，写成 $\Delta L_k(\boldsymbol p)=\boldsymbol\beta_k^\top(\boldsymbol p-\boldsymbol p_{\rm ref})$。这些目标 Loss 与 B7 原生 Loss 无同口径成对标定；我们只报告独立的多目标敏感性，不把 $\Delta L_k$ 加进 $\widehat L_B$，也不声称唯一最优配比或跨规模传递系数。

\subsection{冲突、外推及联合模型结论}

B8 的 calibrated 90/90 组和 extrapolated 60/60 组均表现为 Q 增大、Loss 上升，与 B7 的 45/45 组相反。B7/B8 共有 224 个精确 $N,D,Q$ 坐标而 Loss 全不相同；差值 $B8-B7$ 的中位数为 $-1.1393$。B8 还有 362/1704 个精确 $0.5$ 值，生成机制未给出。我们保持 B8 隔离，不反转 Q 后强行并表。B10 的 128 个 estimated Loss 点对应 B9 元数据，且参数规模全部超出 B1 的 N 范围；它们只用于压力参考，不报告独立外推误差。

现有附件没有在统一 Loss 坐标下同时观测 $N,D,Q_{\rm score},\boldsymbol p$。A 侧 $Q_A$ 到 B 侧 Q、13 个目标 Loss 到 B1/B7 Loss、配比效应跨规模变化的参数都缺少成对识别证据。已识别的分层输出仍是 $\mathcal M_2=[L_B(N,D,Q_B),\{m_k(\boldsymbol p)\}_{k=1}^{13}]$，其中 $m_k=\boldsymbol\beta_k^\top(\boldsymbol p-\boldsymbol p_{\rm ref})$ 只在 A 侧 1M 条件下由 CHM v1.3 估计。它不与 B 原生 Loss 直接相加。

\subsection{四变量可检验条件律与符号来源}

为正面给出题目要求的四变量形式，我们预声明以下\emph{条件}候选，而不将桥接系数当作已估参数：
\begin{align}
r_k(\boldsymbol p)&=\frac{m_k(\boldsymbol p)}{L^A_{k,\rm ref}},\qquad
r_w(\boldsymbol p)=\sum_{k=1}^{13}w_k r_k(\boldsymbol p),\\
\phi_\eta(N)&=(N/N_{\rm ref})^{-\eta},\qquad N_{\rm ref}=1\ \text{十亿参数},\\
L_{\rm cond}(N,D,Q_B,\boldsymbol p\mid\lambda,\eta,w)
&=L_B(N,D,Q_B)[1+\lambda\phi_\eta(N)r_w(\boldsymbol p)].
\end{align}
这里 $L^A_{k,\rm ref}>0$ 是 CHM Ridge 在参考配方的\emph{拟合预测值}，不等于 B 的验证 Loss；$w_k\geq0,\sum w_k=1$ 是决策效用情景。$\lambda\geq0$ 是 A 相对配比效应向 B Loss 迁移的假设倍数，$\eta$ 是假设的规模调节指数；二者均未由现有附件识别。$N_{\rm ref}=1$B 位于 B7 域内，仅给 $\lambda$ 一个清楚的解释锚点。A 侧效应来自 1M，即 $N=0.001$B，位于 B7 支持域外，不构成 1M 的 B 校准。$Q_B$ 保持 B7 原生 $Q_{\rm score}$；CHM 的 $Q_A$ 只作 A 侧辅助诊断，二者无配对映射，不能重复计入同一质量变化。

定义域要求 $N\in[.07,11.97]$、$D\in[10,600]$、$Q_B\in[.1,1]$，$\boldsymbol p$ 为 17 域非负单纯形，且 $H=1+\lambda\phi_\eta r_w>0$。当前实现核验单纯形，但尚无生产者发布的训练配方凸包判别，因此超出该凸包的结果不能称为 A 侧已验证。若某情景使 $L_N,L_D,L_Q$ 改号，也须以该情景的单调性失效报告，不能裁剪输出。$\boldsymbol p=\boldsymbol p_{\rm ref}$ 或 $\lambda=0$ 时 $H=1$，严格回到 B7 joint；进一步取 $Q_B=1$，回到\emph{B7 联合拟合参数}的 $E+AN^{-\alpha}+BD^{-\beta}$，并非独立 B1 拟合的五个数值参数。

设 $H=1+\lambda\phi_\eta r_w$，且 $r_w$ 与独立输入 $Q_B,D$ 无关，则
\begin{align}
L_N&=H L_{B,N}-L_B\lambda\eta\phi_\eta r_w/N,&
L_D&=H L_{B,D},& L_Q&=H L_{B,Q},\\
L_{p_j}&=L_B\lambda\phi_\eta\sum_k\frac{w_k\beta_{kj}}{L^A_{k,\rm ref}}.
\end{align}
可实施的域 $i\to j$ 小幅转移使用 $d\boldsymbol p=d\delta(\boldsymbol e_j-\boldsymbol e_i)$，故 $dL/d\delta=L_{p_j}-L_{p_i}$，并须检查转移后仍在单纯形及有证据的配方支持内。改善弹性为 $\varepsilon_x=-xL_x/L$，与旧 v3 的带符号弹性 $xL_x/L$ 相反。等 Loss 局部替代例如 $dN/dQ_B=-L_Q/L_N$、$dD/dQ_B=-L_Q/L_D$；分母为零、曲面失单调或有限根离开支持域时分别报告未定义或无域内等损失根。线性 Ridge 的组分系数差只代表条件关联，不证明因果互补。

\subsection{识别反例、情景结果与原题数据覆盖}

所有 B 行都没有配方 $\boldsymbol p$，所有 A 配方行都没有 B 原生 Loss 与 $Q_B$。因此 $\lambda=0$ 和 $\lambda=1$ 对 B 行取 $\boldsymbol p=\boldsymbol p_{\rm ref}$ 时给出相同预测，对 A 行也给出相同原生 $m_k$；现有观测不能区别这两组参数，但在非零 $r_w$ 下预测及问题三配置可不同。A 的 1M/60M/1B 对照还改变训练条件且缺完整 $D$，不能单独识别纯 $N$ 指数 $\eta$。这是可检验模型与当前可识别性之间的边界。

预声明分析网格取 $\lambda\in\{0,.25,.5,1\}$、$\eta\in\{-.5,0,.5\}$，目标权重为 arxiv、pile\_cc 单目标及 13 域等权，$N\in\{.1,1,10\}$B、$D=100$B、$Q_B=.5$。配方为参考配方，或从 freelaw、github、pile\_cc 向 arxiv 转移 1\%，另含 arxiv 向 freelaw 的反向转移 1\%，从而覆盖 inferred、direct、near-direct 映射等级。这些范围是敏感性分析，不是置信区间。540 个条件格点均通过正性与单纯形检查。例如在 $N=1$B、$D=100$B、$Q_B=.5$，将 1\% 配比从 freelaw 转向 arxiv，令 arxiv 权重为 1、$\lambda=.5,\eta=0$，则 $r_w=-.0075105896$，B7 基线为 $2.5673967253$，条件 Loss 为 $2.5577553937$。同一曲面在 $Q_B$ 增至 $.6$ 时，保持 Loss 所需的 $N$ 为约 $.78174038$B；两数均可由接口和网格重算，仅是明确假设下的数值例子。

在本预声明网格的 $\lambda>0$ 部分，github 向 arxiv 转移 1\% 对三组目标权重均降低条件 Loss；freelaw 或 pile\_cc 向 arxiv 的方向随目标权重改变。这仅是所给 Ridge、候选桥接与配方点下的排序敏感性，不证明干预有效，也不能外推到未核定的 A 训练配方凸包。逐格范围和映射等级见 \texttt{robustness\_summary.json}。



题目数据门禁的机器结果见 \texttt{requirement\_coverage.json}：B1 主拟合 1176 行；B2 半合成 1029 行与 B3 插值轨迹仅作形状检查；B4 57 行、B5 44 行中各仅 8 行落在 B1 的 $N,D$ 矩形内，且 tokenizer、语料、对数底、聚合方式均未核实，不能合算外测 RMSE；B6/B7 嵌套而 B8 冲突；B9 132 元数据行、B10 128 estimated 行只作域外压力。A 侧 held-out 的 13 target 排序指标由 CHM v1.3 原接口消费，没有重复拟合或把 A12--A15 估算项用作校准。B7 的簇 bootstrap 和嵌套 OOF 不确定性只覆盖 B 原生条件模型，不能吞并 $\lambda,\eta,w$ 与 A/B 映射不确定性。完整四变量\emph{唯一实证预测器}尚不可识别；本文交付的是可计算、可反驳的条件标度律，正式科学准入保持关闭。
