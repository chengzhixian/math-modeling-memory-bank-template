# Q1 符号清单（供第三章统一去重）

章节位置以当前 `q1.tex` 的小节标题表示；总稿插入第二、三章后再统一编号。

| 符号 | 含义 | 类型 | 首次出现位置 |
|---|---|---|---|
| $i,j,k,d$ | 记录、质量指标或训练域、目标验证域、质量域的索引；具体范围在相应公式处给出 | 索引 | 质量数据处理；配比建模 |
| $x_{ij},z_{ij},z^+_{ij}$ | 压缩/变换后的信号、A1 固定尺度的稳健值、方向统一后的值 | 中间量 | 质量数据处理 |
| $A_i,\mathcal M_i,\rho_j,d_j$ | 语义锚点、可用模型信号集、与锚点的秩相关、指标方向 | 中间量 | 质量数据处理 |
| $\mathcal J_{ig},G_{ig},S_i$ | 可用家族指标集、家族均值、三家族综合原始分 | 中间量 | 质量数据处理 |
| $Q_{A,i},Q_{A,d}$ | A 侧样本、质量域综合质量代理 | 评价指标 | 质量数据处理 |
| $\rho_{jr,d},\mathcal E_c,D_i$ | 域内指标秩相关、复制性冲突边集合、样本分歧度 | 评价指标 | 质量冲突 |
| $\boldsymbol p_i,\boldsymbol p,\boldsymbol p_{\rm ref}$ | 17 域训练配比、候选配比、A4 平均参考配比 | 变量/参数 | 配比建模 |
| $L_{ik},\widehat L^{\rm int}_{k,1M}$ | 目标域观测 Loss、1M 二阶交互预测 Loss | 观测/模型输出 | 配比建模 |
| $\boldsymbol\beta_k,\boldsymbol B,\lambda_k$ | Ridge 系数、训练域至验证域线性作用矩阵、正则强度 | 参数 | 配比建模 |
| $a_k,b_{kj},\gamma_{k,uv},\mathcal E$ | 交互模型截距、主效应、两域乘积系数和选中配对集 | 参数/集合 | 配比建模 |
| $m_k^{\rm int}(\boldsymbol p),r_k(\boldsymbol p)$ | 相对参考配方的 1M Loss 差和无量纲相对效应 | 中间量 | 配比建模 |
| $\mathcal P_A,\omega_i,\boldsymbol w$ | A4 观测配方凸包、凸组合权重、13 个目标域的决策权重 | 集合/变量/参数 | 配比建模 |
| $M,c_M,\bar Q_M^{\rm ref}$ | 质量政策覆盖域、覆盖份额、参考配方在覆盖域的条件平均质量 | 集合/中间量 | 配比建模 |
| $F_{\boldsymbol w},\rho^{(h)}_{k,\ell}$ | 加权相对 Loss 决策目标、模型 $h$ 在检验组 $\ell$ 的排序相关 | 目标函数/评价指标 | 配比建模；配比检验 |

注意：$Q_A$ 与附件 B 的 $Q_{\rm score}$ 不在同一已标定坐标；$D_i$ 表示指标分歧度，后续章节的训练 Token 量 $D$ 是另一概念。本文首次使用时已分别定义。本清单不进入第四章正文。
