# Q1 技术路线摘要（供第二章总图使用）

1. **输入**：A1–A3 的 22 项质量信号、A4–A15 的配比和逐目标域 Loss、A16 参考域映射。
2. **质量预处理**：列表信号压缩，A1 上固定变换、稳健标准化及“越高越好”的方向；同一规则用于 A2/A3 全量记录。
3. **质量评价与冲突**：按指标家族汇总样本评分 $Q_A$、聚合七域中位数；以秩相关确定复制性冲突边，用 $(Q_A,D)$ 标记需复核文本。
4. **配比模型**：A4/A5 按 index 配对并将 17 域比例投影到单纯形；逐目标域拟合二阶交互 1M Loss 代理，线性 Ridge 为基线。
5. **条件求解**：在 A4 的 512 条观测配方凸包内，按显式目标权重及 A16 direct/near 质量政策最小化相对 Loss；McCormick 松弛与空间分支定界给数值界。
6. **结果输出**：七域 $Q_A$、冲突分歧及复核规则、13 域相对配比效应、条件可行配方与数值间隙。
7. **验证与边界**：A2/A3 去重扩展复核；A4/A5 嵌套交叉验证，A6–A11 比较排序与误差；A12–A15 仅作估算压力测试。跨规模连续规律及 A/B 质量或 Loss 桥接保持未识别。
