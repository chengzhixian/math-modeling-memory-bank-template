## 1. 技术贡献解释

改用“同类型、共同参数格的标准化六任务均值”分解历史能力增长，与未来q90前沿是两个不同目标。先固定类型/可选开发者权重，再对参数格分布变化和格内能力变化对称分解，两项严格相加；全样本增长与标准化增长的差作为组成/支持差单列，不归为技术。

| 主两月、0.5 decade参数格 | 后训练 | 基础预训练 |
|---|---:|---:|
| 全样本均值变化/分 | 4.222 | -1.192 |
| 标准化均值变化/分 | 5.763 | 0.880 |
| 规模分布项/分 | -0.758 | -3.756 |
| 同参数格内时间项/分 | 6.521 | 4.636 |
| 组成/支持差/分 | -1.542 | -2.072 |
| 条件规模/时间份额 | -13.15% / 113.15% | -426.85% / 526.85% |

这给出明确条件模型的贡献量和份额，**不是残差命名成技术**。同格时间项只有在格内规模差、数据量、选择和评测混杂可忽略时才有技术解释。基础组增长接近零、份额很不稳定，不能报告为可信真实贡献。格宽0.25/0.5/0.75、窗口1/2/3月、开放口径、开发者控制与开发者块抽样结果均已输出。

主后训练共同支持覆盖早期96.0%/末期97.0%；增加开发者控制仅剩6/8条，约1.8%，基础组仅3/2条。这证明严格技术分离受现有样本限制，不能把少数共同开发者结论推广总体。后训练规模份额块抽样5--95%诊断范围约-73.97%至3.53%；抽样重新确定共同支持，不称固定总体的置信区间。

证据：historical_standardized_contributions/common_cells/contribution_bootstrap三个CSV。

## 2. 前沿与放缓预测

新增logit能力的直接q90分位回归，线性规划精确求解。滚动比较常数、两月前沿趋势、分位资源动力学、旧均值资源动力学。训练锚与测试都为两月；测试两完整自然月在训练截点之后，重建当时可见模型版本，C4每折按日截断。每类4个重叠测试窗，都是已查看数据的诊断，不是盲测。

| 模型/两月窗口RMSE | 后训练 | 基础预训练 |
|---|---:|---:|
| 常数 | 3.737 | 7.633 |
| 直接前沿趋势 | 3.053 | 9.571 |
| 均值资源动力学 | 2.237 | 9.763 |
| q90资源动力学 | 2.199 | 10.561 |

回测与未来主点值的参数一致：资源候选eta=.5、时间保留=.5；趋势基线保持原趋势。后训练q90候选仅小幅优于均值候选，不能声称强优势；所有组的R²仍为负，不支持已校准长期准确预测。基础组常数最好，正式比较保留常数，并将资源响应候选作为压力模型，不伪称基础组已识别算力响应。

后训练12月算力对数增长减半的q90候选点53.828，固定假设块抽样5--95%范围50.302--56.007；考虑不同模型/资源速度/时间保留/窗口/分位假设后的条件范围并集37.755--72.236。加入“未来固定偏差不超过历史候选最大误差”的额外压力假设后为31.590--78.400。后一界限假设也未获长期验证，均非未来覆盖概率保证。

24月同候选点66.681；基础组诊断首选常数21.032。各类型从自身最新提交起算，后训练2025-03-13、基础2025-03-09，结果逐行记录origin/target_date。不能与旧v2不同窗口/起点表混用。

局部条件高分位向总体近期前沿的锚定平移仍是一项假设，已经用一致目标诊断但没有完全识别。预测不读取C6或Q3 Loss，因此桥接误差不改变这条直接Benchmark预测；它影响的是Q3能力换算、增益与策略结论，见下节。

## 3. Loss来源坐标与误差影响

逐原始Loss_Source独立拟合，不混合medium成一个Loss坐标；标记validation/training/unspecified。实际消费单调模型留一与常数同源比较：Qwen2标签来源4条RMSE7.048对10.708；Qwen2.5标签来源6条RMSE2.655对15.074。Pythia高可比仍未优于常数，不因高可比就强行使用。来源未知与训练Loss不进入主验证标签候选。

外部核查未确认这些附件Loss数值的具体提取坐标，validation只是附件标签。诊断候选仍只在来源内、支持域内、明示Q3仿射坐标假设时使用；正式接口ready_for_empirical_Q3_conversion=false。

固定Q3 v8快照，计算5来源×36政策×27仿射/上游扰动情景，共4860行。分别保留上游不可行、N超域、Loss超域；不补造分数。仿射scale=.9/1/1.1、offset=-.1/0/.1、上游Loss扰动±.05/0是压力假设，不是估计值或区间。

Qwen2验证标签来源的一些1e20政策“条件增益”可在约-0.121至+2.122分之间变化；另一些支持内情景增益更大。Qwen2.5支持内总体增益范围约-0.188至+6.467分。因此部分“能力提升为正”的结论不稳健，不能只发布名义提升。参考分是同N的B1骨干Loss条件换算，不是实测基线。政策排名仅在所有比较对象可映射时给出，保留并列，不在删掉超域政策后伪造最佳者。

证据：bridge_source_coordinate_models/validation、q3_source_coordinate_stress、q3_bridge_conclusion_sensitivity、q3_policy_ranking_stress。

## 4. C3与C4已实际补算

C4主81条与宽93条都重算资源链。主年对数增速0.690315（4.901倍），宽0.600552（3.986倍）；两套均进入回测和全部12/24月情景，而非仅统计候选数量。

C3逐来源/年份/任务计算实际统计，并给同名年度最后CSV行去重敏感性。原4599行有79个重复Model/Year/Source键。榜单来源去重后2024/2025年均分21.178/22.781、q90为35.100/39.626，参数中位数同为8.03B；这是描述，不能据此宣称规模影响为零。历史报告26行Average与六任务均值平均绝对差9.101分，2020单条Average50而六任务均值7.667，明确证明混接Average会造成错误演进判断。历史零分不自动视为真实能力零，逐任务表保留其覆盖限制。
