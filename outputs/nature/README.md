## 设计与统计契约

每组一个主要论点，面板分别承担结果、机制、基线或边界角色，详见 `manifest.json` 中的 `claim` 与 `panel_roles`。白底、深蓝/紫/灰；分类用点形冗余编码。二维标量采用单调蓝色图，带符号变化采用蓝—白—紫；未使用双Y轴、饼图、rainbow或把配方编号连成趋势。

不重新拟合模型、不制造实验重复或显著性。Q1评分横线是固定规则范围；Q1凸包横线是优化数值界；Q3阈值是数值状态区间；Q4范围是条件自助或确定性假设并集，均在图注中区分。estimated、半合成、未识别桥和曾观察检验明确标记。负预测Loss保留为模型诊断。不可行、超支持和上游缺失留空，不补零。

每图列出全部直接输入路径；`manifest.json` 保存实际输入SHA-256和绘图源文件SHA-256。派生的逐目标配方Loss与去重扩展摘要位于 `source_data/`；其他数据直接对应冻结CSV/JSON，无需维护重复副本。Q1去重中位数仅有答案四位小数摘要，不伪造更高精度。Q4三个前沿目标保持原2025年3月起点。

## QA和复现

源码：`src/visualization/nature_answers.py`；复核：`src/visualization/nature_review.py`。Python依赖numpy/pandas/matplotlib/Pillow/PyMuPDF，另需本地nature-figure的审计脚本。

```powershell
python -B src/visualization/nature_answers.py
python -B src/visualization/nature_review.py
```

默认寻找用户skills目录下nature-figure；可用 `--skill-dir` 指定。`--questions 1,2` 支持按题重跑。重跑后需再次人工看图，不能沿用旧视觉验收记录。

每次渲染执行1.5 pt面板对齐、PDF文本/形状碰撞、实际字形≥5 pt检查；任一硬失败立即终止。实际页宽183 mm，PNG用于浏览，TIFF用于高分辨率排版。审计结果见 `qa/`，静态源预检不代替渲染和人工检查。静态预检可能把中文图例判为大小写异常、把全局最小标签字号与无关数学指数结合推测过小，以及把300 dpi预览判低于600默认；分别由中文排版、逐字形PDF审计和600 dpi TIFF核对解除。没有放宽渲染容差。
