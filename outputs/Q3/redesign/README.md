## 数字与结论范围

- 主方案：质量 q(p) 随配方决定，在 Q1 direct+near 政策和 q≥0.5 下枚举 87 个已观测配方；最优限给定模型与有限候选，不是连续凸包的全局最优。
- 8192 Token、幂成本、10^19 FLOPs：配方477，N≈0.0873B、D=10B、q≈0.5995、Loss≈3.2038；10^22：配方172，N≈6.6607B、D≈193.8735B、q≈0.6714、Loss≈2.0944。
- 477→172 的主扫描数值括区为 [1.610535,1.610648]×10^19 FLOPs。图中定位线是括区中点，不是精确物理阈值；另一假设扫描有略不同的数值括区，不能混用来源。长上下文极窄状态未保证穷尽。
- 10^24 下 N、D 触及 [11.965825B,299.893B] 支持上界；8192 Token 幂成本仅用约2.76%预算。未用部分不能解释为继续投入无效。
- 注意力/基础训练=Lc/30000，是题面成本代理的代数关系。30000 Token 是两项相等位置，不是模型能力阈值；不含质量成本，C7长上下文支持稀疏。
- 9个单因素情景仍为24/27格可行，但去除配比桥（λ=0）令全部24个可行格配方改变。可行性稳定不等于配方选择稳定。
- 独立 Q_B 投入方案固定172，使用B7半合成质量坐标；不同于主方案的q(p)，不以两条曲线差值宣称清洗质量的实测因果收益。
- 公开OpenLM外测只有可比N/D与同语料验证Loss，无可对齐Q/p；本任务复算发布表排序，不重新抓取/训练，不声称完整四变量真实最优验证。
- A/B桥未标定、质量与配比贡献重复尚未识别。Q1负交叉熵代理的有效性问题仍存在；Q3优化数值证书不能修复上游科学有效性。
