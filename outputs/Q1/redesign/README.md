## 必须保留的科学边界

1. Q_A 是 A 侧工程代理，不是人工质量真值或 B 原生 Q；区间只覆盖固定规则下的抽样不确定性。
2. A6–A11 曾影响模型形式判断，不能称完全未触碰的最终盲测。1B 中 47/64 配方在 A4 凸包外。
3. 10B/70B 表为 estimated/extrapolated 压力证据。
4. 连续凸包可行配方与离散候选 index 必须分别报告。
5. 二元贡献是 γ_uv p_ref,u p_ref,v / L_ref 的模型项组成，不是两域因果协同或可行增配的总效应。
6. 发现主模型非物理预测：等权无质量约束连续可行解的 Mathematics 预测 Loss 为 **−0.09010146768555932**，参考为 3.830527802897536，相对下降 102.35219%。该结果不得包装成实际性能改善。需由 Q1 负责人修正代理有效域或非负性约束后，重跑优化、数值界与下游敏感性。参见 `experiments/visualization/20260926-q1-redesign-review.md`。

运行环境：Python 3.12；版本见 manifest。依赖 matplotlib、numpy、pandas、Pillow 及 SciPilot 脚本。
本机独立解释器位置记录在交接文件，不写入绘图逻辑。
SciPilot 已实际剖析六份结果 CSV，报告 `scipilot_profiles.json`；“模型/目标编号”是分类标签，不能照自动类型建议连成连续曲线。`decision_panel.csv` 的无约束质量字段 NaN 表示政策不适用，不作为绘图数值。

八图布局检查无 FAIL/WARN，逐图查看完成；PNG 文件通过严格格式/DPI 检查。
SciPilot PDF 检查器对 Type0 字体报“可能未嵌入” WARN；直接以 PyMuPDF 提取每张图的字体，常规与粗体均得到非空 TrueType 字体数据，属复核后排除的误报。

旧图仍有线性基线的合理用途，但不能冒充当前交互主模型。特别是旧 `q1_interaction_heatmap.png` 为 Ridge 主项显示归一化矩阵；v2 的效应依赖当前配方，不能继续把它称为固定的 v2 作用矩阵。旧消融图的 4/13 比较 Ridge 与常数；新图 03 的 13/13 比较交互与 Ridge，两个分母不同，不能写成同一指标发生矛盾。
