## 1. 数据质量的答案

A1 共 51,230 条记录，每条由 22 个信号预处理、列表压缩、统一方向、稳健标准化后得到相对质量代理 Q_A。领域汇总使用样本评分中位数。主口径的七域顺序与数值为：book 2.9183、arxiv 2.6887、commoncrawl 0.4367、stackexchange 0.2517、wikipedia -0.2944、c4 -0.3040、github -0.4854。数值是 A1 内部评分坐标，不是人工真值，也不能直接作为附件 B 的原生质量坐标。

A2/A3 使用完全冻结的 A1 评分规则，不重新定向或标准化。去除与 A1 重叠的记录后，arxiv 16,104 条、github 193,752 条的领域中位数分别为 2.7279、-0.5063；与 A1 对应的 2.6887、-0.4854 接近。五个信号在留一领域时方向翻转，规则变更可改变部分域排名，因此固定规则的抽样区间不等于方法选择不确定性的完整区间。完整评分、方向和敏感性结果由 outputs/Q1/domain_quality.csv 与 outputs/Q1/quality_robustness.json 给出。

## 2. 指标冲突及处理的答案

对统一方向后的 22 个指标计算 231 对 Spearman 相关，各数据范围分别控制 BH-FDR 0.05。A1 总体有 66 对显著负相关，其中 55 对在去重 A2/A3 扩展集按冻结规则复现。这是指标排序分歧的统计证据，不是因果冲突的证明。

每条文本保留二元评价 (Q_A,D)：Q_A 为综合质量代理，D 为复制性冲突边上的加权指标分歧。以 A1 冻结阈值 Q_A=0.0273、D 的第 75 百分位=2.0423 标记低优先级或需复核，分歧高不直接扣除质量分，无可用边记缺失并触发复核。A1 的保留、保留并复核、低优先级、低优先级并复核分别为 20,384、5,231、18,038、7,577 条。27 条原文案例用于解释规则，不构成人工标签，故不计算分类准确率。冲突图、阈值和原文核查证据由 outputs/Q1/conflict_validation.json 等冻结记录提供。

成因解释以数据现象与文本语义为依据：例如专业性信号与平均词长在七域内持续负相关，高频二元和三元字符信号也持续给出相反排序；公式宏、代码格式、版权头和长文本结构会让不同信号抓住不同侧面。领域混合还可能造成总体与域内相关不同。因而采用“综合质量 + 分歧复核”的工程处理，而不把某一个冲突指标机械地判为错误，也不把这些解释写成已证实的因果机制。

## 3. 配比与 Loss 关系的答案

A4+A5 给出按 index 配对的 512 个 17 域配比及 13 个目标域的 1M 验证 Loss。先将每行三位小数舍入后的配比归一化到非负单纯形。正式逐目标域模型为：

L̂_k(p) = a_k + Σ_j b_kj p_j + Σ_(u,v)∈E γ_k,uv p_u p_v，|E|=10。

交互域从 A4 中按方差选择，逐目标正则强度在训练集五折选择。线性 Ridge 只作基线。对参考配方 p_ref 定义相对效应 r_k(p) = [L̂_k(p)-L̂_k(p_ref)] / L̂_k(p_ref)，分母是正的 1M 交互拟合参考 Loss。交互系数刻画所选组成坐标下的关联，不是两域的因果协同；实际增减某域必须从其他域转移比例。

17 个主项描述各训练域的条件作用，十个乘积项描述其配比组合带来的非加性变化；13 个目标域各有一套系数，因此影响方向与大小随目标域和当前配方而变。模型可直接给出指定配方的逐目标 Loss、相对效应与可行转移梯度，完整系数在 outputs/Q1/interaction_coefficients_13_targets.json。配方排序与下述多目标决策展示了这些单域及组合效应的综合结果。

A4+A5 嵌套五折外层预测中，交互模型 13/13 个目标的 RMSE 低于 Ridge；目标域 RMSE 中位数为 0.4499，对照为 0.4921。A6–A11 真实检验组的 1M、60M、1B 同条件比较中，分别有 11/13、13/13、13/13 个目标的交互 RMSE 更低，逐目标排序 Spearman 中位数为 0.8512、0.8474、0.7912。A6–A11 曾影响模型形式判断，因此是已观察比较证据，不是完全未触碰的最终盲测。A6/A8 使用相同 256 个配方，不能按独立配方组重复计数；1B 有 47/64 个配方在 A4 凸包外。

## 4. 条件性配方决策的答案

支持集限定为 A4 的 512 个已观测配方凸包。默认目标权重为 13 域等权；质量约束仅在 A16 direct 或 direct+near 可映射域上使用 A1 sample 主评分，要求覆盖份额及已覆盖加权质量不低于参考配方。其余 11 个 inferred 域不臆造质量数值。考虑等权加权目标和保护最差目标两种决策；具体权重、政策必须随配方一起报告。

| 情景 | 可行目标上界 | 数值目标下界 | 间隙 |
|---|---:|---:|---:|
| 等权、无质量约束 | -0.115112 | -0.116074 | 0.000962 |
| 等权、direct | -0.102992 | -0.103433 | 0.000441 |
| 等权、direct+near | -0.097010 | -0.097760 | 0.000750 |
| 最差目标、无质量约束 | -0.019784 | -0.020780 | 0.000996 |

四份连续凸包可行配方、质量约束残差及目标上界已由 outputs/Q1/numerical_signoff.json 独立重算通过；完整 17 维配方在 outputs/Q1/hull_bounds.json。McCormick 松弛加空间分支定界给出间隙小于 0.001 的浮点数值上下界，不是严格数学证明。若只能从原 512 条中选择，等权无约束、direct、direct+near、minimax 的有限集合最优 index 分别是 136、301、172、477；这四个 index 不是上述连续凸包解的替代编号。

训练扰动敏感性进一步限定具体推荐：30 次无放回抽取 80% A4+A5 行，重新选交互特征、正则并拟合后，在 512 个已观测候选中，上述四个原 index 分别被再次选中 29、10、13、7 次。因此无质量约束等权的离散候选较稳；质量约束及 minimax 应呈现情景候选与假设，不能只报一个似乎固定不变的配方。这不是连续凸包解的置信区间。

## 5. 外推表与有效范围

A12–A15 的 10B/70B Loss 是附件外推估算，不是真实大模型训练实验；两组各 63 个配方均已在 A4 出现。冻结 v2 与估算 Loss 的逐目标 Spearman 中位数为 0.4915、0.3941，略低于 Ridge 的 0.5136、0.4148。等权候选内部比较中，两种 1M 代理均选 index 16，它在两组估算表均排第 61/63。故估算表不能支持跨规模配方排序稳健的主张。它只构成明确的负向压力测试，不能反过来当作重新挑选 v2 模型的训练数据。

附件 A 未给出与配方实验成对的训练数据量 D，也没有 Q_A 与 B 原生质量坐标、Q1 目标域 Loss 与 B 侧 Loss 的成对标定。Q1 因而给出 A 侧质量代理、冲突感知评价、1M 配比相对效应、情景配方和已声明的验证范围；不从 A 附件单独拟合连续尺度律，不宣称 10B/70B 真正最优配方或跨来源绝对 Loss 改善。
