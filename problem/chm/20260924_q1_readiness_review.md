# 问题一初稿就绪复核（2026-09-24）

结论：chm 负责的第一问经验分析已达到**可写论文初稿**的程度；尚不足以宣称七域质量分数已被证明能直接改善 B 侧 Loss，或配比效应在任意大规模都具有精确预测能力。论文初稿以 `paper/sections/chm/q1_draft.md` 为准。

## 已核实的证据

- A1 的 51,230 条记录及 A2/A3 扩展集均已处理；22 指标的方向、稳健标准化、家族平衡和域内冲突有运行产物。A1 与扩展集重叠，故另以非重叠记录复核 arxiv/github 的 Q 中位数（2.7146/-0.5363）。扩展集只覆盖两域，不能代表全部七域。
- A4+A5 的 512 条训练配方用于逐目标域 Ridge；A6–A11 留作 1M/60M/1B 检验。13 域 Spearman 中位数依次为 0.8381/0.8381/0.7067。A6/A8 的相同 256 配方直接比较，中位 Spearman 为 0.9944；1B 是不同的 64 条配方。
- 无配比消融的 RMSE 中位数在 1M/60M/1B 为 0.6759/1.4724/3.2514，完整代理为 0.4478/1.4450/3.2079；1B 仅 4/13 个目标域得到 RMSE 改善。跨规模结果应强调排序，不应夸大绝对 Loss 精度。
- 经验尺度参数 eta=0.1450，目标域 bootstrap 95% 区间 [0.1069,0.1867]，目标域加校准样本双层 bootstrap 区间 [0.0976,0.2010]。只有三个真实规模，且 1B 支持集不同；两种区间均条件于已拟合的 Ridge。
- A12–A15 属 estimated/extrapolated；63 条配方均已在 1M 训练集中出现。这是附件外推值的内部压力测试，不是 10B/70B 真实验证。

## 初稿必须保留的限制

1. Q 是 A 数据派生的描述性指数，而 B6–B8 `Q_score` 是官方附件给出的半合成字段。二者没有成对标定，不能作恒等、MinMax 或其他任意数值变换接入 B 模型。
2. 质量家族删除消融中，去掉 RPS 后七域排序 Spearman 降到 0.8214，4/7 域名次改变；方向、标准化等替代方案较稳定，不代表家族定义无关紧要。现有 Q 的置信区间只量化固定评分规则下的记录重抽样误差。
3. 17 个配方域在 A16 中仅 3 个 direct、3 个 near-direct；其余 11 个 inferred，不应制造 17 个精确 Q。13 个 Loss 目标也不能直接等同于 B1 `val_loss`。
4. 22 指标两两负相关目前是描述性冲突；相关强度的区间及多重比较尚未完成，论文不作显著性判断。非线性代理、外部语料质量验证属于后续增强，不阻塞初稿。
5. A17 官方域摘要为辅助资料；当前主模型没有将其作为训练标签或额外质量真值。整合定稿时可用它核对域覆盖与抽样差异，不应据此改写 A1–A3 原始信号。
