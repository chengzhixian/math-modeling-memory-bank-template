# Q3 条件配置接口

正式输入由 Q1 `chm.q1.v2.0`、Q2 v8 冻结模型、题面成本代理、C7 上下文长度和明示的 A/B 质量及配比桥接假设组成。`src/chm/q3_conditional_v8.py` 计算固定配方、87 条可行 A4 配方联立选择和原生 Q 敏感性；`outputs/Q3/manifest.json` 记录当前 main 的代码、输入、论文和结果哈希。

输出含预算可行性、条件 Loss、选定配方与数值界。越界、不可行或未识别的跨坐标量不能解释为真实训练最优。82 个结构转移括区和九组单因素情景只是声明网格内的数值与假设压力；公开外部模型仅验证 N/D 子结构排序。见 [Q3 完整答卷](../../outputs/Q3/ANSWER.md)与[实验索引](../../experiments/Q3/README.md)。
