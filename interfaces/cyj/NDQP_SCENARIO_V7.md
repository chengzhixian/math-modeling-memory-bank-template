# CYJ conditional NDQP interface v7

`cyj.ndqp.scenario.v7` consumes signed CHM Q1 v2 (`c621f7e405106e42720f918f490235b5e8becefb0f7c8cb997736e96337117a9`) and the frozen CYJ B7 coefficient vector. It is a **conditional scenario predictor**, not a cross-source empirically calibrated model. The user-facing baseline assumes `bridge_lambda=1`, `eta=0`, and `exp_bridge`; all outputs retain the uncalibrated status.

Run `python -B src/cyj/ndqp_scenarios_v7.py --describe` or `--request interfaces/cyj/fixtures_v7/baseline_main_supported.request.json` with NumPy and SciPy installed. `src/cyj/build_q2_v7.py` regenerates policy results; `src/cyj/build_v7_fixtures.py` regenerates request/expected pairs. Their exact dependencies and environment belong in the release handoff.

The request has `schema_version`, `mode`, `N_params_B`, `D_tokens_B`, `Q_score`, a complete 17-domain `p`, nonnegative unit target `weights`, and `p_policy`. `mode=baseline` rejects bridge overrides. `mode=bridge_sensitivity` requires `bridge_lambda`, `eta`, `bridge_model` (`exp_bridge` or `linear_bridge`). N and D use billions; Q is native B7 `Q_score`, not Q1 `Q_A`. The input is restricted to the B7 box N `[.07,11.97]`, D `[10,600]`, Q `[.1,1]` and Q1 supported mixtures. The A-side quality score screens a mixture under the declared policy; it does not supply Q_B.

`p_policy` supports `observed_512`, `convex_hull`, `quality_direct`, `quality_direct_and_near`, and `algebraic_reference_only`. The last accepts p_ref as an algebraic identity check and reports whether it is in the Q1 hull; it must not be used as an off-hull Q3 candidate. Quality policies require both coverage and mapped mean at least their p_ref values; unmapped domains remain unknown.

The baseline equation is `L_B(N,D,Q_B) * exp(r_w(p))`, with `r_w=sum_k weights[k] * (L_A,k(p)/L_A,k(p_ref)-1)`. Sensitivity changes the exponent to `bridge_lambda * N**(-eta) * r_w`. The linear comparison is `L_B*(1+bridge_lambda*N**(-eta)*r_w)` and rejects nonpositive factors. Both modes return Loss, B7_loss, r_w, factor, signed elasticities and N/D/Q/p ambient derivatives. The p derivatives are ambient; physical mixture changes require feasible directions within the hull and quality policy.

The bridge is `sensitivity-only`: no paired A/B observations identify amplitude, N decay, A-to-B Q mapping or absolute Loss transfer. Positive bridge amplitudes preserve p ranking for a fixed N/D/Q/weights and common feasible set; that identity is an implementation check, not empirical validation. At fixed p, baseline N/D/Q elasticities and the quality-versus-scale root equal the frozen B7 result. Q3 owner acceptance and main integration are separate gates.

The published output under `outputs/cyj/q2_v7/` includes policy candidates with numerical lower/upper bounds, source-specific validation summaries, formula diagnostics and limitations. CHM's four equal-weight/minimax cases are re-run against the current main bytes by `revalidate_q1_v2_bounds.py`. The historical CHM signoff audit has a different bounds-file hash; `upstream_pin.json` records the discrepancy and CYJ acceptance of the numerically reproduced current file. CYJ additionally bounds the arxiv-only and pile_cc-only continuous-hull cases with the same numerical method in `single_target_hull_bounds.json`; these two are not CHM-owner signed. Observed finite-set results are exact only among the 512 recipes. None of the floating-point gaps is an interval-arithmetic proof. v6 remains unchanged.

For independent CYJ acceptance, compile `paper/latex/main.tex` twice with XeLaTeX, run `python -B src/cyj/audit_q2_v7.py`, then `python -B src/cyj/finalize_q2_v7.py`. The last command reruns the builder, verifies deterministic hashes, 21 request/expected pairs (including corrupted manifest and model-file identity), all CYJ regressions, policy algebra, source bounds, uncertainty role and Q2 TeX layout before setting the conditional-Q2 status. Its result does not set `q3_consumer_verified` or empirical A/B calibration.
